## Rules

1. **≥ 1440px — the side menu is part of the layout.** It sits on the left and pushes the content;
   the user can collapse it to icons (navbar off). See widths on the Grid page.
2. **< 1440px — the side menu is hidden.** It opens from the burger on top of the content,
   which gets dimmed. The column grid does not move.
3. **1920px is roomy, 1440px is compact.** The side menu keeps the same structure, only its
   spacing and the logo shrink (table below).
4. **Columns:** 12 on computers and tablets, 4 on horizontal mobiles, 2 on vertical mobiles.
5. **Spacing** always follows the 8px module ([Spacing](?path=/docs/foundations-spacing--docs)).

## Themes

The app has a **light** and a **dark** theme. Components use `--theme-*` tokens, and the value
switches with the `data-theme` attribute on `<html>` (or on any block):

```html
<html data-theme="dark">
```

```css
.navbar { background: var(--theme-app-bg); color: var(--theme-nav-text); }
```

Without the attribute, the light theme is used. In Storybook, switch the theme with the
**Theme** button in the toolbar.

## Notes on the Figma source

- In the templates only the screen background and the side menu are drawn; the menu icons and the
  logo here are placeholders until the Navbar component is added.
- The templates for 1280px and below are empty: there is no header with the burger yet, so it isn't
  drawn here either.
- The 1280px template is 1280×832, while the Grid board uses a 1280×720 frame.
- **Hover Blue** changes between themes (#6368DF light, #4549A1 dark); the dark value is the same
  colour as the existing `--color-headlines`.
