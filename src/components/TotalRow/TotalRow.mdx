# TotalRow

Summary bar under a table or order: caption and large total on the left, actions on the right. Implements the Figma frame
[`Row.Total`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=78-27027)
(1524px wide in the mockup, here 100% of the container). Built from [Button](?path=/docs/atoms-button--docs).

## Figma → code mapping

| Figma | Code |
|---|---|
| Frame `Row.Total` (White, padding 16, `justify-between`, Cards Shadow) | `.ds-total-row` |
| `total-price`: “Total” (Semi-Bold h7) | `label` |
| `total-price`: “$19140” (Semi-Bold h1, 40/60) | `total` |
| `button_action v1` (Dark BG, icon only 37×37) | `<Button variant="dark" iconOnly="download-cloud">` via `onDownload` |
| `button_action` “View doc” (Dark BG, padding 8/16, icon left) | `<Button variant="dark" size="medium" iconLeft="tick">` via `onViewDoc` |

Icons were matched by look to the 16px set (`download-cloud`, `tick`); swap them in `TotalRow.tsx` if the designer meant others.

## When to use

- ✅ Directly below a table, cart or order where the grand total and document actions are shown.

## When NOT to use

- ❌ Per-row totals inside a table — use `TableProductsRow`.
- ❌ Other action sets — compose your own bar from `Button`.

## Accessibility

- The icon-only button has `aria-label` (`downloadLabel`, default “Download”).
- Both buttons are native `<button>`s reachable with Tab.
