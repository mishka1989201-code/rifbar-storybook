# LabeledField

A caption above a form control. Implements the Figma component [`Input/Title`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=147-86319): Body/Small Medium title, 4px gap, an `InputField` below.
It composes the existing `InputField` atoms — the control is passed as `children`, so the same molecule serves `InputField`, `TextField` and `FilterField`.

## Figma → code mapping

| Figma | Code | Notes |
|---|---|---|
| `Input/Title` | `<LabeledField title="Name">` | root, column, gap 4 |
| text “Name” | `title` | Body/Small Medium, Color Text |
| `InputField` (static, empty) | `children` = `<InputField placeholder="…" />` | field states come from the atom |
| frame width 188.667px | container width | the code takes 100% of the parent; Figma width is only the frame size |

## When to use

- ✅ A field that needs a visible caption in a form, modal or filter panel.

## When NOT to use

- ❌ A field whose meaning is clear from its own placeholder (search, table filters) — use the bare `InputField`.
- ❌ A group of radios / checkboxes — they have their own labels; use a `fieldset` with `legend`.

## Figma notes

- Figma draws one state: caption + empty static field. Focus, error and disabled come from `InputField` (see its description in Figma).
- The title is a single `<label>` around caption and control, so clicking the caption focuses the control and screen readers read it as the control's name.
- `Modal` has its own `ModalField` with identical styling (it predates this component); it was left unchanged.
- No new tokens. Dark theme not designed — token values follow the theme automatically.

## Accessibility

- The `<label>` wraps the control, so the caption is its accessible name; do not add a second `aria-label`.
- The field is 32px high — below the 44px touch target; kept as designed.
- Grey Dark placeholder `#5D6E82` on white is above 4.5:1; the empty-state border (Stroke Light V2) is below 3:1 — kept as designed.
