# SelectProducts

The opened part of a product row on the client's *Custom price* tab: a **Select all** checkbox and the product lines to pick, in two columns.
Implements the Figma [`Select Products`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=1299-429127) frames (flavours; and `Backpacks` with photos, node `1299:437151`).

## When to use / When NOT to use

- ✅ Choosing products or flavours of one group before making a discount.
- ❌ A product table with columns — use `TableRowExpandable`. A confirmation list in a dialog — use `CheckListModal`.

## Figma notes

- Figma draws “Select all” unchecked when only some lines are checked (second block): there is no partial state. The code keeps that.
- Not drawn, AI-defined: disabled line (`--opacity-disabled`), long names (ellipsis), the empty list (header only), one column in a container narrower than 640px, the keyboard focus (from `Checkbox`).
- Figma sets the name column to 200px wide; in code the name takes the free width and the price is pushed to the right edge (the same look at the Figma sizes).
- The photos of the `Backpacks` block could not be downloaded (asset proxy 403): the stories use demo photos.
- Dark theme: no dark Figma frame shows this block — all dark values are **AI-defined** (name `#646464`, price `#BDC5E2`, crossed-out `#646464`, discounted and “Select all” `#888CF6`; the cards use the Table Row dark tokens). Story `All variants (dark theme)`.

## Accessibility

- Every line is a native checkbox labelled by its name; “Select all” is a native checkbox too.
- ⚠️ Secondary Grey crossed-out prices (`#A7A4B7` on white) and Grey Dark names are kept as designed; the crossed-out price is below 3:1.
- ⚠️ The 24px checkbox is below the 44px touch target (desktop control, as designed).
