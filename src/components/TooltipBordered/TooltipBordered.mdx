# TooltipBordered

A white hint bubble with a **border, an arrow and a soft shadow**, for tooltips with richer content
(a headline + text). Implements the Figma component set
[`Tooltip with border + shadow`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=73-57190)
— 4 positions × 2 width modes. Figma note: “appears on hover; white type — for more complex content”.

## Figma → code mapping

| Figma | Prop | Value |
|---|---|---|
| `Position=Left` | `position="left"` (default) | Bubble left of the target, arrow on the right edge |
| `Position=Right` | `position="right"` | Arrow on the left edge |
| `Position=Top` | `position="top"` | Arrow on the bottom edge |
| `Position=Bottom` | `position="bottom"` | Arrow on the top edge |
| `Width mode=Fixed` | `widthMode="fixed"` (default) | 300px bubble (+ 8px arrow slot), text wraps |
| `Width mode=Hug` | `widthMode="hug"` | One line, as wide as the text |
| Instance override in `Hover Row in Table` (BG Color fill, Stroke Light V2 border, Secondary Grey headline) | `tone="subtle"` | Not a Figma property; a separate tone, light and dark values from `--tooltip-bordered-subtle-*` |
| `Show headline` | `title` | Headline, Headings/h6 Medium. Empty = hidden |
| `Show body text` | `children` | Body, Body/Small Medium. Empty = hidden |

## When to use

- ✅ A hint with a headline and a sentence or two (explaining a field, a limit, a status).
- ✅ On hover or keyboard focus of an element that needs more explanation.

## When NOT to use

- ❌ A one-word label on an icon — a simple dark tooltip is enough.
- ❌ Something the user must read or act on — use a message or a modal, a tooltip disappears.
- ❌ Interactive content (links, buttons) — a tooltip is not focusable.

**Figma notes:**
- In Figma `Fixed` is 308px for Left/Right and 297px for Top/Bottom. Same bubble, a 3px inconsistency —
  in code both are a 300px bubble.
- The `Space adjust` layers (0.01px, only in `Hug`) are spacing helpers and are not rebuilt.
- `subtle` is drawn in `Hover Row in Table` (light and dark) as an override of the component instance: fill BG Color, stroke
  Stroke Light V2, headline Secondary Grey, body Color Text; the bubble is 899px wide there, so the caller sets the width
  (`style`, or the layout around it). Dark values are the ones drawn in that frame. The dark shadow reuses the light Tooltip Shadow (Figma has no dark one).
- Body text is a `<div>` now, so `children` can be several `<p>` paragraphs (Figma draws two paragraphs).
- Showing/hiding on hover and the placement next to the target are not part of the atom.
- Empty, loading and error states are not applicable (static text).

## Accessibility

- Has `role="tooltip"`. Connect it to the target with `id` + `aria-describedby` on the target, and show it
  on both hover **and** keyboard focus; hide it on `Escape`.
- Text is Primary Blue Dark on White (15:1) and the Headlines border is 7.7:1 against White.
- It is not focusable and must not contain links or buttons.
- `subtle`, computed: body `#292639` on `#F6F8FC` 13.81:1 (dark `#C9C6D9` on `#101010` 11.38:1).
- ⚠️ Kept as designed: the `subtle` headline `#A7A4B7` on `#F6F8FC` is 2.29:1 (dark `#646464` on `#101010` 3.22:1), below 4.5:1; its border
  is 1.23:1 against the fill in both themes (the shadow separates it).
