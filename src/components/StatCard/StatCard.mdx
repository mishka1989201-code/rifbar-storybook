# StatCard

Number card: a caption and a big number, with either a link and a watermark (V1) or a right-aligned amount (V2). Implements the Figma [`Card`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=7038-332399) Property 1=Card.InProcessingV1 / V2 as one component.

## Figma → code mapping

| Figma | Code |
|---|---|
| `Card.InProcessingV1` (column, padding 16, 1px Secondary Light) | `label` + `value` + `footer` + `watermark` |
| `Card.InProcessingV2` (row, padding 12/16) | `label` + `value` + `aside` |
| “See all >” (`button_action` Text & Arrow) | `footer` = `<Button variant="text-arrow">` |
| `Logo` 62×89 | `watermark` |

## When to use

- ✅ Dashboard metrics on mobile.

## When NOT to use

- ❌ Process steps — use `StepCard`.

## Dark theme

Figma "Dark Molecules Components" → `Card In processing Dark`: card `#000000`, stroke `#27282E`, label and “See all” `#BDC5E2`, number `#888CF6`, watermark `#2F3156` (opaque; light is `#BDC5E2` at 60%). Story: `DefaultDark`.

The `--color-*` rows above are light values; the dark values come from the themed tokens listed in the last rows.

The watermark size (62×89) is in CSS as is; the sign paths are the same as in `Logo`.

## Accessibility

- The watermark is `aria-hidden`; the link in `footer` needs a clear label.
- Dark theme contrast: number 7.13:1, label 12.25:1; watermark `#2F3156` on `#000000` 1.69:1 (decorative).
