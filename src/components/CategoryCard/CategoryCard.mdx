# CategoryCard

Small tile for a category grid: a picture and a centred one-line name. Implements the Figma component
[`Card Category`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=3843-306191)
(Property 1 = Static / Hover).

## Figma → code mapping

| Figma | Code |
|---|---|
| Frame, White, 1px Stroke Light V2, radius 14, padding 4/4/8, Cards Shadow | `.ds-category-card` |
| `image 423` (radius 10) | `image` |
| Title (Body/Mini Medium, Color Text, centred, ellipsis) | `title` |
| Property 1=Hover (Headlines border, Hover Small Cards shadow) | `:hover` / `:focus-visible` |

## When to use

- ✅ Category or collection grid where a picture and a name are enough.

## When NOT to use

- ❌ Product with price, specs and action — use [ProductCard](?path=/docs/molecules-productcard--docs).

## Code example

```tsx
import { CategoryCard } from 'rifbar-ds';

<CategoryCard image="/img/astro.png" title="Disposables" href="/catalog/disposables" />
```

## Accessibility

- With `href` the whole tile is one link named by `title`; the picture has empty `alt` by default so the name is not read twice.
- Without `href` it is plain content; make it interactive yourself if needed.
