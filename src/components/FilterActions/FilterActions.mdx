# FilterActions

Mobile toolbar above a list: a “Filter” button with a badge of applied filters and a full-width search field below it.
Implements the Figma frame [`Actions`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=1114-420275). It is composed of existing atoms: [Button](?path=/docs/atoms-button--docs) and [SearchField](?path=/docs/atoms-searchfield--docs).

- ✅ Mobile / narrow list screens where filters open in a panel and search sits under them.

## When NOT to use

- ❌ Desktop table toolbar with Export / Clear — use [TableActionsRow](?path=/docs/molecules-tableactionsrow--docs).

## Figma notes

- Figma draws only one state (“Filter [4]” + empty search). Hover / focus / disabled come from the `Button` and `SearchField` atoms; not designed here, taken by analogy with them.
- In Figma the button label, icon and the badge are Headlines `#4549A1`; the `Button` outline atom uses Primary Blue Dark text and badge, so they are overridden inside this molecule only.
- The filter icon in Figma is an unnamed glyph (funnel); matched to the existing `filter-dark` by appearance (`filter-light` is a sliders icon, not the same) — to be confirmed by a designer.
- The badge is hidden when `filterCount` is `0` / `undefined` (AI-defined).
- Dark theme not designed — light values are used.

## Accessibility

- Container is `role="toolbar"`; the filter button has a visible label, the search field has `aria-label="Search"`.
- Secondary Grey `#A7A4B7` placeholder on white is below 3:1 contrast — kept as designed.
- Desktop-size controls: the filter button is 37px high (below 44px touch target) — kept as designed; the search field is 40px.
