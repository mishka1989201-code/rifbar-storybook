# Dropdown

The menu panel that opens from a trigger: a list of options (plain, with radio or checkbox, with or without search), a notifications panel and the user menu.
Implements the Figma component set [`Dropdown`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=32-55784) — 8 `Style` values that differ only in their rows, so **one component** with `variant`, `control` and `searchable`.

It draws **only the panel**. Opening, positioning, outside-click and `Esc` belong to the trigger ([FilterField](?path=/docs/atoms-inputfield--docs), [UserDropdown](?path=/docs/molecules-userdropdown--docs)…).

## When to use

- ✅ Choosing from a short list (status, filter, person), notifications under the bell, the user menu under the avatar.

## When NOT to use

- ❌ A rows-per-page selector — [ShowSelect](?path=/docs/molecules-showselect--docs). A list taller than ~8 rows without search — add `searchable`.

## Figma notes

- Figma draws the hover row with `BG Color` (`Standart`) or `rgba(245,246,248,.8)` (`Radio Button` / `Checkbox`); in code both use `--color-bg` (`#F6F8FC`), the difference is not visible.
- In `Notification` the first row has the `BG Color` fill — read as **unread** (`unread`); Figma does not say what it means. **To be confirmed by a designer.**
- The divider in `User Dropdown` is an SVG line whose colour could not be read (asset download returns 403); `--color-stroke-light-v2` is assumed.
- The e-mail in `User Dropdown` is Hover Blue `#6368DF` (as in Figma), which is below 4.5:1 on white.
- Not designed, AI-defined: the empty state of a search (“Nothing found”), disabled option (20 %), keyboard focus ring (`--shadow-focus`), pressing rows in `Notification` (shown as buttons only when `onNotificationClick` is passed), the empty `Notification` panel (only “See all”). Dark theme not designed — light values are used.
- Notification icon: the same unnamed warning glyph as in `NotificationLine`, matched to `warning-v2` and coloured Warning.
- Figma draws the panel with a `drop-shadow` filter; the code uses `box-shadow: var(--shadow-tooltip)` (same six layers).

- Node `7061:44267` is a second Figma set of the same dropdowns **with their triggers**; only the panels are the `Dropdown`. The scrolling list is new: `maxRows` wraps the rows in `Scrollbar variant="dropdown"` (3px track `Stroke Light V1`, thumb `Text`). In Figma the scrollbar overlays the rows at the panel edge; in code it takes 3px of the row width.
- The sort trigger is the 37×37 outline `Button` with the `sort` icon (Figma: fill `#F1F2F9`, stroke `#CBC8DB`; the icon is an unnamed raster asset, matched by look — to be confirmed). Figma shows its default state only; `aria-expanded` is the AI-defined open state.
- Figma draws the User panel above its trigger (the menu opens upwards in the header); positioning is left to the parent.
- Not designed, AI-defined: keyboard focus on the scrolling list (`tabIndex=0` from `Scrollbar`, `--shadow-focus` on rows).

## Code example

```tsx
import { Dropdown } from 'rifbar-ds';

<Dropdown
  control="checkbox"
  searchable
  options={[
    { value: 'david', label: 'David Schwimmer' },
    { value: 'matthew', label: 'Matthew Perry' },
  ]}
  value={selected}
  onChange={(v) => setSelected(v as string[])}
/>

<Dropdown variant="notifications" notifications={items} onSeeAll={openAll} />
<Dropdown variant="user" name="David Schwimmer" email="david@example.com" onAction={handleAction} />
```

## Accessibility

- `control="none"`: `role="listbox"` with `role="option"` rows (`aria-selected`, Enter / Space). `radio` / `checkbox`: native inputs from the `Checkbox` atom in a `radiogroup` / `group`; radios of one panel share a generated `name`.
- `variant="user"`: `role="menu"` with `menuitem` buttons. The trigger should set `aria-haspopup` / `aria-expanded` and handle `Esc`.
- Rows are 37px high and the 16px radio / checkbox are small targets — below the 44px touch target, kept as designed.
- Grey Dark `#5D6E82` rows pass 4.5:1; Secondary Grey `#A7A4B7` (search placeholder, empty text) and Hover Blue `#6368DF` (e-mail, about 4:1) are below the text contrast target — kept as designed. Disabled at 20 % is below 3:1.
- Dark theme contrast: row text `#BBC7D6` on `#000000` 12.25:1, selected `#050411` on `#BBC7D6` 11.87:1, hover on `#242424` 9.06:1, accent 7.13:1, e-mail `#6368DF` 4.58:1, notification `#BDC5E2` on `#242424` 9.05:1.
