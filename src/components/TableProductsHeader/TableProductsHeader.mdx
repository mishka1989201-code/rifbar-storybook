# TableProductsHeader

Dark header row of the products table. Implements the Figma frame
[`Table Products Header`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=78-26106)
(1524px wide in the mockup, here 100% of the container). Pure text cells; the frame is named “Header with Sort”
per cell in Figma, but no sort icons are drawn in this design.

## Figma → code mapping

| Figma | Code |
|---|---|
| Frame `Table Products Header` (Primary Blue Dark, padding 8/16, `justify-between`) | `.ds-table-products-header` |
| `ID` cell “#” (30px, centered) + `Header with Sort` “Name” (170px), group gap 32 | columns `id` + `name`, `group: 'lead'` |
| “Flavor/Group” 230, “Type” 203, “Nicotine” 59 | columns `flavor`, `type`, `nicotine` |
| “Quantity” (auto width, right-aligned) | column `quantity`, `align: 'end'` |
| `Amount` “Ampunt” 75px, right-aligned | column `amount`, `align: 'end'` |

“Ampunt” is the label as drawn in Figma (typo for “Amount”) — kept for fidelity; override it via `columns`.

## When to use

- ✅ Header of the products table in the ERP.

## When NOT to use

- ❌ Tables with other column sets that need sorting — extend `columns` and add sort controls separately.
- ❌ Mobile layouts: cells have fixed widths.

## Accessibility

- `role="row"` with `role="columnheader"` cells; use it inside an element with `role="table"` (or `grid`).
- White on `#1D2542` text contrast is well above AA.
- Dark theme contrast: `#BBC7D6` on `#242424` 9.06:1.
