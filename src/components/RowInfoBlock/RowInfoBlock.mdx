# RowInfoBlock

A row of an info list with a bottom line: caption + value, a larger "info line", or a multi-column order line.
Implements the Figma component set [`RowInfoBlock`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=7045-348261) — three variants of one row, so one component with a `variant` prop.

## When to use

- ✅ Lists of facts in an order / warehouse details panel; `cells` for item lines (name · flavor · quantity).

## When NOT to use

- ❌ Label above value in a card — use [InfoClient](?path=/docs/molecules-infoclient--docs). A short card line without a bottom line — use [CardStrokeRow](?path=/docs/molecules-cardstrokerow--docs).

## Figma notes

- `compact`: the value column in Figma is 14px Medium like the caption (not Regular as in `line`). A value that is a control, e.g. the Status `ChevronDropDown`, is not cut by the ellipsis.

- `line`: Figma uses fixed columns 200px + 16px + 300px; in code they are a `2fr / 3fr` grid, so they scale with the container and match at 516px.
- `cells`: Figma gives the columns 47 / 160 / 30px; in code the first and last cell hug their content and the middle ones share the remaining space and are centered — identical position at 518px.
- Figma shows the three variants with different widths (582 / 516 / 518); in code the row is 100% of its container.
- The hidden `Image and Name` wrapper in `Info Line 1` holds only the caption, no image is drawn.
- Not designed, AI-defined: long text is cut with an ellipsis; first cell of `cells` is limited to 40% of the row; 8px minimum gap in `pair`/`cells`; dark theme — light values are used.
- `cells` color roles (first = Color Text, others = Grey Dark) follow the Figma frame.

## Dark theme

Figma "Dark Molecules Components" → `Info v2 Dark`: values `#BDC5E2` (Primary Blue Dark Light), labels `#5D6E82` (unchanged), row lines `#242424`. Only the `compact` / `line` variant is drawn in dark; `pair`, `stacked` and `cells` are AI-defined by analogy (strong text `#C9C6D9`, muted `#646464`, lines `#242424`). Story: `AllVariantsDark`.

## Accessibility

- Plain text in a `div`. For a real list of facts wrap rows in your own `<ul>`/`<dl>`.
- Secondary Grey #A7A4B7 (`line` caption) on white is below 3:1 contrast — kept as designed. Grey Dark #5D6E82 on white passes.
- Dark theme contrast: muted `#646464` on `#000000` 3.55:1 (⚠️ below 4.5:1, AI-defined).
