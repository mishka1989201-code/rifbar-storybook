# InfoBlock

Bordered info card: a title row and a body of label/value pairs, or — in the `ticket` variant — of sections with a “Change” pill. Implements the Figma component
[`InfoBlock.board_all-orders`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=32-10609)
(1290px wide in the mockup, here 100% of the container). It only composes existing molecules:
[CardHeader](?path=/docs/molecules-cardheader--docs) (title row) + [InfoClient](?path=/docs/molecules-infoclient--docs) (body).

## Figma → code mapping

| Figma | Code |
|---|---|
| Frame `InfoBlock.board_all-orders` (White, 1px Stroke Light V1, radius 10, Cards Shadow, clip) | `.ds-info-block` |
| Instance `Row.HeaderCard` “Client info” | `<CardHeader title icon actions>` |
| Frame `Info` → `info_client` (6 label/value pairs) | `<InfoClient {...infoProps}>` (or your `children`) |

### Variant `ticket` — Figma [`TicketInfo/v1`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=139-47455)

| Figma | Code |
|---|---|
| Frame `TicketInfo/v1` (White, 1px Stroke Light V2, radius 10, Cards Shadow, 400px) | `variant="ticket"` |
| `head Card` — violet ellipse + “Responsibility” | `CardHeader tone="violet"` (set automatically) |
| `Information 1` (padding 16) with two `Section.Department` | `sections={[{ title: 'Department' }, { title: 'Manager' }]}` → [DepartmentSection](?path=/docs/molecules-departmentsection--docs) |

The last section has no bottom line. Without `sections` pass your own `children`.

The title row line is Stroke Light V2 here (the standalone `Row.HeaderCard` frame uses Secondary Light), so `InfoBlock` overrides that one border color.

## When to use

- ✅ Info card of a client / order / document on a details page.

## When NOT to use

- ❌ Only a title row — use `CardHeader`. Only label/value pairs without a card — use `InfoClient`.

### Size `mobile` — Figma [`board_all-orders`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=208-95123) at 320px

Same card as the default one; the title row and the `InfoClient` body have 10px side padding instead of 16px (`size="mobile"`). The fields wrap onto several lines (pairs, then the e-mail alone with an ellipsis), so use `infoProps={{ justify: 'start' }}` as in Figma (gap 16 / 32).

## Design tokens used

| Token | Property | Value | Source |
|---|---|---|---|
| `--color-white` | background | `#FFFFFF` | Figma: White |
| `--color-stroke-light-v1` / `--border-width-sm` | card border | `#F1F2F9` / `1px` | Figma: colorBorders (Stroke Light V1) |
| `--radius-lg` | card radius | `10px` | Figma: radius 10 |
| `--shadow-card` | drop shadow | `0 30px 25px -20px rgba(0,0,0,.1)` | Figma: Cards Shadow |
| `--color-stroke-light-v2` | title row bottom line; card border in `ticket` | `#D8E2EE` | Figma: Stroke Light V2 |
| `--spacing-16` | body padding in `ticket` | `16px` | Figma: Information 1 padding 16 |
| `--size-form-column` | column width in `form` | `508px` | **New** · Figma: Information 4 / 5 width. Added 2026-10-09 |
| `--spacing-32` / `--spacing-16` / `--color-secondary-light` | column padding / gap in `form` / title row line | `32` / `16px` / `#ECEEFB` | Existing tokens.json · Figma: py 32, px 16, gap 16, Secondary Light |
| `--spacing-10` | side padding in `mobile` | `10px` | Existing tokens.json · Figma: board_all-orders 320px padding 10 |
| `--spacing-24` / `--spacing-16` | body padding in `details` | `24px` / `16px` | Existing tokens.json · Figma: Information 1 padding 24 / 16 |
| `--color-stroke-light-v2` | card border in `details` | `#D8E2EE` | Existing tokens.json · Figma: Stroke Light V2 |

Everything inside comes from `CardHeader`, `InfoClient` and `DepartmentSection` (see their docs). The only new token is `--color-violet-tint` (violet badge, in `CardHeader`).
The Figma `ticket` frame is 400px wide; here it is 100% of the container. Long titles and narrow containers are AI-defined.
In `details` the Figma `Status` is a `ChevronDropDown` “Open” (`primary` colour, as drawn); the card has no list of statuses — opening it is up to the parent.
`actions` slot and custom `children` are AI-defined (not in Figma).

## Code example

```tsx
import { InfoBlock } from 'rifbar-ds';

<InfoBlock title="Client info" />

<InfoBlock
  variant="ticket"
  title="Responsibility"
  sections={[{ title: 'Department' }, { title: 'Manager' }]}
/>

<InfoBlock
  title="Order info"
  icon="cart"
  infoProps={{ justify: 'start', fields: [{ id: 'order', label: 'Order', value: '#10428' }] }}
/>
```

## Accessibility

- Rendered as a `<section>` whose heading is the `CardHeader` `<h3>`; the body is a description list (see `InfoClient`).
