# EmailChevron

A recipient in a “To:” / “Cc:” field: **avatar + name + ×**. The × removes the recipient. Implements the Figma component
[`Email - Chevron`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=5620-292268).
Built from [Avatar](?path=/docs/atoms-avatar--docs) (`size="xs"`) and [Icon](?path=/docs/atoms-icon--docs) `xmark`.

## Figma → code mapping

| Figma layer | Prop / part | Value |
|---|---|---|
| Pill | — | Stroke Light V1 fill, Secondary Grey stroke 1px, padding 2px, fully rounded |
| `Department Avatar` 20px | `name` / `avatarSrc` → `<Avatar size="xs" />` | Hover Blue, initials Body/Micro Medium |
| Name text | `name` | Body/Mini Medium, Grey Dark |
| `Icons 16px` (12px) | `onRemove` | `xmark`, Grey Dark |

## When to use

- ✅ People chosen as email or message recipients.
- ✅ Any “chosen people” list where each one can be removed (assignees, watchers).

## When NOT to use

- ❌ An applied filter — use [FilterChevron](?path=/docs/atoms-filterchevron--docs).
- ❌ A status — use [ChevronStatus](?path=/docs/atoms-chevronstatus--docs).

## Code example

```tsx
import { EmailChevron } from 'rifbar-ds';

{recipients.map((r) => (
  <EmailChevron key={r.id} name={r.name} avatarSrc={r.photo} onRemove={() => remove(r.id)} />
))}
```

## Accessibility

- × is a real `<button>` named “Remove David Schwimmer” (change with `removeLabel`).
- The avatar is decorative here — the name is written next to it.
- Contrast: name Grey Dark on Stroke Light V1 — 4.7:1 ✅; avatar initials White on Hover Blue — 4.6:1 ✅.
