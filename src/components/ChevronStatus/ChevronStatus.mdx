# ChevronStatus

A colored pill with a short status: order, payment, stock, employee status. Implements the Figma
component set
[`Chevron.Status`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=73-83771)
— 8 colors + optional icon. Not interactive: it has no hover, focus or disabled states.

| Danger | `color="danger"` | Danger Strong | White |
| Light | `color="light"` | BG Color | Grey Dark |
| Dark | `color="dark"` | Primary Blue Dark | White |
| Icon = true | `icon` | — | `arrow_drop_up` before the text, 4px gap |

## When to use

- ✅ Showing the status of a row in a table or of a card (Paid, Cancelled, In delivery).
- ✅ One status per item, 1–3 words.

## When NOT to use

- ❌ Something you click — use [Button](?path=/docs/atoms-button--docs).
- ❌ A number on an icon (unread count) — use the [Icon](?path=/docs/atoms-icon--docs) counter / dot.
- ❌ Long explanations — use text or an alert.

## Code example

```tsx
import { ChevronStatus } from 'rifbar-ds';

<ChevronStatus color="success">Paid</ChevronStatus>
<ChevronStatus color="danger">Cancelled</ChevronStatus>
<ChevronStatus icon iconLabel="Up">13.6%</ChevronStatus>
```

## Accessibility

- For a trend, pass `iconLabel="Up"` — screen readers read “Up 13.6%”. Without it the arrow is decorative (`aria-hidden`).
- A plain `<span>`: screen readers read the text. The color only repeats the meaning — always write the status in words.
- Contrast of the text (12px Semi-Bold needs 4.5:1):

| Color | Contrast | |
|---|---|---|
| Primary | 4.6:1 | ✅ |
| Secondary | 5.2:1 | ✅ |
| Success | 4.7:1 | ✅ |
| Info | 7.7:1 | ✅ |
| Warning | 4.6:1 | ✅ |
| Danger | 4.6:1 | ✅ |
| Light | 4.9:1 | ✅ |
| Dark | 15.1:1 | ✅ |
