# ClientDetails

Free-text note block of a client card: a light-grey rounded card with a grey caption and a multi-paragraph text. Implements the Figma frame
[`Client Details`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=32-10673)
(1290px wide in the mockup, here 100% of the container). Usually sits below [CardHeader](?path=/docs/molecules-cardheader--docs)
and [InfoClient](?path=/docs/molecules-infoclient--docs).

## Figma → code mapping

| Figma | Code |
|---|---|
| Frame `Client Details` (White, padding 0 16 32) | `.ds-client-details` |
| `Content` (BG Color, 1px Stroke Light V2, radius 10, padding 16, gap 2) | `.ds-client-details__card` |
| “Detailed information” (Body/Standart Medium, Secondary Grey) | `title` |
| Two paragraphs (Body/Standart Regular, 24px line, 12px gap) | `children` (string split on blank lines, or any node) |

## When to use

- ✅ Free-form notes, comments or description of a client / order.

## When NOT to use

- ❌ Structured label/value data — use `InfoClient`.
- ❌ Editable text — use a text field.
