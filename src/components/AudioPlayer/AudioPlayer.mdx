# AudioPlayer

A card with an audio visualizer, elapsed / total time with a timeline, a play / pause button and a volume control.
Implements the Figma frame [`Player - Time Tracker`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=5346-1491949).

## When to use

- ✅ Playing back a short audio recording (call, voice note) in a card or a side panel.

## When NOT to use

- ❌ Time tracking controls (Play / Stop, date, scale) — see [TimeTrackerBar](?path=/docs/molecules-timetrackerbar--docs). Long media with playlists — a full media player.

## Figma notes

- **Assets:** the Figma asset URLs (visualizer, timelines, icons) returned 403 through the proxy, so the shapes are drawn in CSS from the render. The bar heights (`DEFAULT_PLAYER_LEVELS`, 32 bars) and the 8px handle were measured on the Figma screenshot; the icons are the existing `pause` / `play` / `volume-up` at 32px.
- Figma draws only the **playing** state (pause icon) with the handle at the start. Not designed, AI-defined: the `play` icon when paused; focus ring (`--shadow-focus`) on the button and handles; volume “muted” look (only the handle at the left); all bars stay dark (the visualizer does not show progress); dark theme — light values are used.
- The inactive track colour has no Figma variable; it is `#D6D7EA`, read from the render and equal to Headlines at 22 %. **Needs confirmation.**
- Figma width of the card is 338px; the code is 100% of the container, the visualizer (203px) stays centred and the timeline stretches.
- The filter “Cards Shadow” is a `drop-shadow` in Figma; code uses `box-shadow: var(--shadow-card)`.

## Code example

```tsx
import { AudioPlayer } from 'rifbar-ds';

<AudioPlayer
  playing={playing}
  currentTime={time}
  duration={150}
  volume={volume}
  onPlayPause={() => setPlaying(!playing)}
  onSeek={setTime}
  onVolumeChange={setVolume}
/>
```

The component is controlled: it does not play audio itself — drive `currentTime` / `playing` from your `<audio>` element.

## Accessibility

- Both ranges are native `<input type="range">` with `aria-label` (“Seek”, “Volume”); the button has `aria-label` “Play” / “Pause”. The visualizer is decorative (`aria-hidden`).
- Controls are 32px (button) and 8px-high ranges — below the 44px touch target, kept as designed.
- The inactive track (`#D6D7EA` on white) is about 1.4:1 contrast — kept as designed. Headlines `#4549A1` time text passes 4.5:1 but the Light (300) weight is thin.
