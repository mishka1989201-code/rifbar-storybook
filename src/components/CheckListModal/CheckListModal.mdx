# CheckListModal

A dialog with a list of options to tick — for example the statuses to filter by. Implements the Figma frame
[`Info Modal`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/%F0%9F%93%B1-ERP-System-v-1.1--Mockups----Rifbar-2023%F0%9F%93%B1?node-id=769-306160): a Semi-Bold title and a chevron button in the header, then rows with the text at the left and a
24px checkbox at the right. It is a **molecule**: the surface is the existing [Modal](?path=/docs/molecules-modal--docs)
(new `size="list"`, `elevated`, `headerAction`), the header button is [Button](?path=/docs/atoms-button--docs) and the rows use
[Checkbox](?path=/docs/atoms-checkbox--docs).

| Hidden: `date-range-apply` | not part of this component — use [DatePicker](?path=/docs/organisms-datepicker--docs) |

## When to use

- ✅ Choosing several values from a short list: statuses, categories, warehouses.

## When NOT to use

- ❌ Choosing exactly one value — use a radio list (`RadioGroupCard`) or a `Dropdown`.
- ❌ A form with fields — use [Modal](?path=/docs/molecules-modal--docs) with `ModalSection`.

## Figma notes

What Figma draws: one dialog, *Status*, with *All* and seven statuses, every checkbox checked; three layers are hidden (a description, a search box and a calendar).

Not drawn, defined by analogy (AI-defined):

- **Unchecked** — the Chosen / Unchosen shapes of the `Checkbox` atom; **hover / focus / disabled** rows — from `Checkbox`.
- **`All`** — checked when every enabled row is checked, otherwise empty (no “some” state: the atom has none). Disabled rows are not changed by `All`.
- **Search** — filters the rows by their text; `All` is hidden while the field has text; an empty result shows “Nothing found”.
- **Description** — Figma puts it in the header, under the title; the `Modal` header has no such slot, so it sits at the top of the body.
- **Long labels** wrap; **narrow containers** — the dialog fills them.
- **Dark theme** — not designed: the light values are used.

Normalised or assumed:

- The header button has a chevron up: Figma does not say what it does; it is exposed as `onCollapse` (the dialog is not closed by the component).
- The rows are not `RowInfoBlock`: that molecule has a Stroke Light V2 line and a grey value, this frame uses Stroke Light V1 and a checkbox, so the rows are drawn here with the same 16px padding.
- The Tooltip Shadow is the `--shadow-tooltip` token (box shadow); Figma draws it as drop shadows with half the blur, which look the same.
- Row text is Medium Color Text (`#292639`); the `Checkbox` atom's own label is Regular Primary Blue Dark, so the color and weight are overridden here.

## Accessibility

- `role="dialog"` labelled by the title (from `Modal`); add `aria-modal`, a focus trap and `Esc` in the page that opens it. The list has an accessible name; each row is a native checkbox inside its label, so the whole row is clickable.
- The header button has an accessible name (`collapseLabel`).
- Contrast (calculated): row text `#292639` on white 14.68:1; title 15.05:1; white tick on `#4549A1` 7.72:1; unchosen box `#5D6E82` 5.23:1; chevron on Secondary Light 13.03:1.
- ⚠️ Kept as designed: the lines between rows (Stroke Light V1) are 1.12:1 against white; the 24px checkboxes and the 37px header button are below the 44px touch target (the row itself is 56px high and fully clickable).
