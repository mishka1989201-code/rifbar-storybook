# TableRowOrder

One order of the client's *Orders* tab — as a table row on desktop and as a card at 768px and below. Implements
[`Table Row 14`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/%F0%9F%93%B1-ERP-System-v-1.1--Mockups----Rifbar-2023%F0%9F%93%B1?node-id=818-311773)
and [`Card Row 4`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/%F0%9F%93%B1-ERP-System-v-1.1--Mockups----Rifbar-2023%F0%9F%93%B1?node-id=818-311200)
as ONE component with a `layout`. It is a molecule: [Button](?path=/docs/atoms-button--docs) +
[ChevronStatus](?path=/docs/atoms-chevronstatus--docs).

## Figma notes

What Figma draws: the row at 1524px with seven statuses over several rows, the card in two content variants (price + type, or client + phone),
at 348px (two columns, 768px) and 448–308px (one column, 480 / 360px). Pictures are not involved: the “More” icon is the existing `info` icon.

Not drawn, defined by analogy (AI-defined):

- Hover / focus of the name (as `TableRowClient`) and the hover of the row — the row is not clickable itself, only its name and button.
- Long text: row cells are cut with an ellipsis; card cells wrap (`overflow-wrap: anywhere`).
- Dark theme: not designed — the light values are used.

Normalised or assumed:

- In the card Figma lets the status chip join the first line when there is room (480px) or go to a second line (768px, 360px); this is plain flex wrapping with a 16px gap.
- The Figma card name is Semi-Bold, the 2nd cell Medium, the 3rd Semi-Bold, the date Medium — kept as drawn, so “Purchase” is bolder than “$1200”.
- The `Status` and `Actions` cells of the row keep their own size (no ellipsis) so the chip and the focus ring are never clipped.

## Dark theme

Figma "Dark Molecules Components" → `order-list__item` / `board_all-orders Dark`: the `--table-row-*` tokens (row `#000000`, stroke `#242424`, text `#C9C6D9`); the status pills and “More” button come from the atoms. Story: `AllVariantsDark`.

## Accessibility

- `role="row"` with `role="cell"` cells; put the rows inside an element with `role="table"` (`TableOrders` does).
- The status is text in the chip, not colour alone. The name is a link or a button when `nameHref` / `onNameClick` is set.
- Contrast, computed: row text `#292639` on white 14.68:1; chips (white text): Pending `#5D6E82` 5.23:1, In work `#4549A1` 7.72:1, Approved `#1D2542` 15.05:1, In shipping `#00864E` 4.65:1, Rejected `#DF2E15` 4.63:1, Received `#6368DF` 4.59:1; “Awaiting payment” `#5D6E82` on `#F6F8FC` 4.92:1.
- ⚠️ Kept as designed: the “More” button is 37px high (below 44px); the cards are separated from the page by a 1.06:1 shadow only.
- Dark theme contrast: text 12.56:1.
