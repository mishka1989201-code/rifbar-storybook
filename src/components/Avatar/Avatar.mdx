# Avatar

A person's or a department's photo, or their initials when there is no photo. One code component for three Figma
components:
[`ava`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=48-10482),
[`Chat Avatar`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=137-33886),
[`Department Avatar`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=139-48421).
Not interactive: if it should open a profile, wrap it in a link or a button.

## When to use

- ✅ `user` — the signed-in user in the Navbar.
- ✅ `chat` — a person: chat, comments, assignee, email recipient.
- ✅ `department` — a team or department (Delivery, Warehouse…). The square shape tells it apart from a person.

## When NOT to use

- ❌ The company logo — use [Logo](?path=/docs/atoms-logo--docs).
- ❌ An icon of an action — use [Icon](?path=/docs/atoms-icon--docs).

**Figma notes:**
- The `ava` fill `#141D3F` has no color style in Figma (raw value). It is the same raw color as the Switcher pill, so the
  token `--color-avatar-bg` points to `--color-switcher-bg-light`. Worth making it a real color style.
- The `ava` drop shadow (`1px 2px 2px` Hover Blue 15%) is not on the Shadows board — added as `--shadow-avatar`.
- `Department Avatar` has a hidden `Icons 16px` layer (a ✓ tick, Primary Blue Dark). It is not in code yet — ask design
  where it is used (selected state?). Primary Blue Dark on Hover Blue would be only 2.9:1.
- Inside `Email - Chevron` the instance is called “Department Avatar” but it is round, 20px, with Medium 10px text.
  In code this is `variant="chat" size="xs"` (a recipient is a person).
- Initials text is Regular in `ava` / Chat / Department but Medium at 20px. Kept as in Figma.

## Dark theme

Figma frames **Dark Atoms Components → `ava - Dark`**, **`Chat Avatar`**, **`Department Avatar - Dark`**: themed `--avatar-*` tokens, light values unchanged. See **AllVariantsDark**.

- `user` (ava): fill `#050411`, initials `#BBC7D6`, shadow Dark Mode Shadow 2 (`--theme-avatar-shadow`, already themed; the avatar now reads it instead of `--shadow-avatar`, same value in light).
- `chat` / `department`: fill `#4549A1` (Headlines), initials `#000000`.

## Accessibility

- By default the avatar is an image named after the person (`role="img"`, `aria-label="David Schwimmer"`) and shows
  the full name on mouse hover.
- If the name is already written next to it (chat list, Email - Chevron), pass `decorative` — otherwise screen readers
  read the name twice.
- Contrast of the initials:

| Variant | Contrast | |
|---|---|---|
| `user` — White on `#141D3F` | 16.4:1 | ✅ |
| `chat` / `department` / `xs` — White on Hover Blue | 4.6:1 | ✅ (12px and 10px need 4.5:1) |
- Dark theme contrast (calculated): `user` initials 11.87:1; ⚠️ `chat` / `department` black initials on `#4549A1` **2.72:1** (below 3:1) — as designed, flag to design.
