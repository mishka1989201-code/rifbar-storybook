# SuccessCard

A card with a big green hexagon check and a Light 32px message — the result of an action, e.g. “The Discount is Successful”.
Implements the Figma [`Successfully v2`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=1334-460992) frame (478 × 340 for the discount message).

## Figma → code mapping

| Figma | Code | Notes |
|---|---|---|
| `Successfully v2` | `.ds-success-card` | Stroke Light V1 fill, Green Light @ 9% stroke, radius 10, green shadow, padding 32, gap 10 |
| `Objects` → `Group` (192 × 218) | `illustration` (default: inline SVG) | Drawn from its measured shape |
| “The Discount is Successful” (Light Headings/h2) | `title` | Headlines, 32 / 48, centred |

## When to use / When NOT to use

- ✅ A short, positive result of a bulk action, shown for a moment over the page.
- ❌ Inline form feedback — use `MessageBox` / `Notification`.

## Figma notes

- The illustration asset could not be downloaded (asset proxy 403). The hexagon (outline 21px, vertical sides) and the check (24px stroke, with a gap cut in the hexagon) are drawn in SVG from the shape measured on the render — **the curves differ slightly from the vector in Figma**; replace the SVG with the original when it is available.
- Figma draws the card without an overlay and does not say how long it stays: showing, centring and closing are left to the page.
- Dark theme: no dark frame — all dark values are **AI-defined** (fill Primary Blue Dark (Dark), title `#888CF6`, the green and its 9% stroke unchanged, shadow Dark Mode Shadow 1).
- Not drawn: a long message wraps and centres (AI-defined).

## Accessibility

- `role="status"`; the illustration is decorative (`aria-hidden`).
- ⚠️ Headlines `#4549A1` on `#F1F2F9` is 6.91:1 (fine; `#888CF6` on the dark fill is 6.91:1 too). The green illustration (1.72:1 on the panel) is decorative and carries no meaning.
