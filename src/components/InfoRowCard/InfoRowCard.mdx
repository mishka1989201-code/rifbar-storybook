# InfoRowCard

A two-column line of an info card: a semi-bold caption on the left (200px) and a value that fills the rest.
Implements the Figma component [`InfoRow.Card 1024px`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=181-81235) (412px wide in the mockup, here 100% of the container).

## When to use

- ✅ Rows of an info card on desktop pages ("1024px" in the Figma name).

## When NOT to use

- ❌ Rows with a bottom line — use [RowInfoBlock](?path=/docs/molecules-rowinfoblock--docs). Caption above value — use [InfoClient](?path=/docs/molecules-infoclient--docs).

## Figma notes

- The name says "1024px": presumably there are other breakpoints, but only this one is in the linked frame. Mobile is not designed, so none is assumed.
- The label column is 200px but can shrink (`flex: 0 1`) in a narrow container. AI-defined.
- Long text is not designed. AI-defined: it wraps (long words break) instead of being cut.
- Figma has no line-height on the label (100% in the style); `--font-line-height-h7` (21px) is used, like the value.
- Dark theme not designed — light values are used.

## Dark theme

Figma "Dark Molecules Components" → `Info Line Card 1024px Dark`: label `#5D6E82`, value `#BDC5E2`. The code has one `color` for the row (AI-defined: both `#BDC5E2`; Figma greys the label). Story: `DefaultDark`.

## Accessibility

- Plain text in `div`s. For a list of facts wrap rows in your own `<dl>` / `<ul>`. #292639 on white has high contrast.
- Dark theme contrast: `#BDC5E2` on `#000000` 12.25:1.
