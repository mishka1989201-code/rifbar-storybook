# StepCard

Process step tile: a round icon, a step name and a date. Implements the Figma [`Card`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=7038-332399) Property 2=Step.

## Figma → code mapping

| Figma | Code |
|---|---|
| Frame Step (White, 1px Stroke Light V2, radius 10, padding 24, Cards Shadow) | `.ds-step-card` |
| `Admin Icons` circle 50px (#E6FCE6) + `Document add` 24px | `icon` (default `doc-new`) |
| “New” (Medium h5) / “08/12/2022” (Grey Dark) | `title` / `caption` |

## When to use

- ✅ Steps of an order or document flow.

## When NOT to use

- ❌ Numbers and metrics — use `StatCard`.

## Dark theme

Figma "Dark Molecules Components" → `Step 1 Dark`: card `#101010` (BG Dark), stroke `#242424`, icon ellipse `#161C16` (new value-named colour `--color-green-pale-dark`), title `#BDC5E2`, date `#5D6E82` (unchanged). Story: `DefaultDark`.

| Token | Property | Value | Source |

Badge size 50px with 6px padding is taken from Figma as is (no size token).

## Accessibility

- The icon is decorative; the step name is the `<h3>`.
- Dark theme contrast: title `#BDC5E2` on `#101010` 11.1:1, date `#5D6E82` 3.64:1 (⚠️ below 4.5:1, kept as designed).
