# StepCard

Process step tile: a round icon, a step name and a date. Implements the Figma [`Card`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=7038-332399) Property 2=Step.

<Controls of={StepCardStories.Default} />

## Figma → code mapping

| Figma | Code |
|---|---|
| Frame Step (White, 1px Stroke Light V2, radius 10, padding 24, Cards Shadow) | `.ds-step-card` |
| `Admin Icons` circle 50px (#E6FCE6) + `Document add` 24px | `icon` (default `doc-new`) |
| “New” (Medium h5) / “08/12/2022” (Grey Dark) | `title` / `caption` |

## When to use

- ✅ Steps of an order or document flow.

## When NOT to use

- ❌ Numbers and metrics — use `StatCard`.
