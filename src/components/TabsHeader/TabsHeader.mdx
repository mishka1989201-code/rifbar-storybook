# TabsHeader

White bar with a row of [Tabs](?path=/docs/atoms-tabs--docs) at the top of a card or page section. Implements the Figma frame
[`Tabs Header`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=13-13595)
(7 tabs, first one active, 1202px wide in the mockup).

## Figma → code mapping

| Figma | Code |
|---|---|
| `Tabs Header` frame (white, radius 6 top, 1202px) | `<TabsHeader>`; width = 100% of the container |
| `Tabs` Tab #=Active | `items[i].id === value` |
| `Tabs` Tab #=Not Active | any other item |
| `Tabs` Tab #=Disabled | `items[i].disabled` |

## When to use

- ✅ Switching between sections of one page or card.

## When NOT to use

- ❌ Filtering a list — use [SwitchButtons](?path=/docs/atoms-switchbuttons--docs).
- ❌ A single tab on its own — use the `Tab` atom.

## Dark theme

Figma "Dark Molecules Components" → `Tabs Header Dark` / `Hover Tabs`: bar background `#000000` (White Dark), active tab and underline `#888CF6`, inactive tabs `#5D6E82` (unchanged). The bar background is the only own colour (`--tabs-header-bg`); the tabs inherit the dark theme from the `Tab` atom. Story: `DefaultDark`. Hover Tabs in Figma matches the atom hover (AI-defined there). Nothing to confirm.

## Design tokens used

| Token | Property | Value | Source |
|---|---|---|---|
| `--color-white` | bar background | `#FFFFFF` | Figma: Theme Color/White |
| `--radius-md` | top-left / top-right corners | `6px` | Figma: Tabs Header corner radius 6 (top only) |
| `--tabs-header-bg` | bar background | `#FFFFFF` / dark `#000000` | **New** · Figma: Tabs Header Dark → fill = White (Dark) |

The `--color-*` rows above are light values; the dark values come from the Dark theme tokens listed in the last rows.

Tab colors, typography, padding and underline: see the [Tabs](?path=/docs/atoms-tabs--docs) atom. No new tokens.

## Code example

```tsx
import { TabsHeader } from 'rifbar-ds';

const [tab, setTab] = useState('general');

<TabsHeader
  aria-label="Client"
  value={tab}
  onChange={setTab}
  items={[
    { id: 'general', label: 'General' },
    { id: 'orders', label: 'Orders (12)' },
    { id: 'archive', label: 'Archive', disabled: true },
  ]}
/>
```

## Accessibility

- `role="tablist"` with `aria-label`; each tab is a `role="tab"` button with `aria-selected` (from the `Tab` atom).
- Contrast and touch target: same as the Tab atom (7.7:1 active, 5.2:1 inactive, 53px high).
- Dark theme contrast: active `#888CF6` on `#000000` 7.13:1, inactive `#5D6E82` on `#000000` 4.02:1 (script).
