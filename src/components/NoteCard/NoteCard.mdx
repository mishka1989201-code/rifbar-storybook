# NoteCard

A note: its text in a light-grey box, an optional "more" link at the end, and the date with a clock icon under it. Implements the Figma component set
[`Notes`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/%F0%9F%93%B1-ERP-System-v-1.1--Mockups----Rifbar-2023%F0%9F%93%B1?node-id=3843-307004) — 2 variants: Static and Hover.

| `more` (Medium, Headlines) | `onMore` + `moreLabel` |
| `Date`: clock icon 16px + `07.23.2023` | `date`, `dateTime` |
| Frame: padding 16, gap 16, radius 10, width 1524 | `.ds-note-card` (fills its container) |

## When to use

- ✅ A free-text note, comment or remark with the date it was written.

## When NOT to use

- ❌ A chat message — use [ChatMessage](?path=/docs/molecules-chatmessage--docs).
- ❌ A caption plus text inside a card — use [ClientDetails](?path=/docs/molecules-clientdetails--docs) (same grey box, no outer card).

## Figma notes

What Figma draws: Static and Hover with two paragraphs, the cut text ending in "…", the "more" link and the date.

Not drawn, defined by analogy (AI-defined):

- Focus ring of "more" (2px Headlines outline) and its hover colour (Hover Blue, as other links); a note without the link or without the date; short text; an unbroken long word; narrow container.
- Dark theme: not designed — light values are used.

Assumed / normalised:

- The text is already cut in Figma ("…tellus..." + "more"). The card does **not** cut text itself (a line clamp does not work across several paragraphs): the parent passes the shortened or the full text and decides when to hide the link.
- The card is not a link: only "more" is interactive, so Hover is a pure look. If the whole card should open the note, wrap it in a link — not designed.
- Figma draws the shadows as drop shadows (`0 30 12.5` and `0 20 10.5`); the existing Cards Shadow and Hover Large Cards box shadows are used (same effect on a filled card).
- The grey box is the same as in `ClientDetails` (BG Color, Stroke Light V2, radius 10, padding 16); it is repeated here rather than shared, because `ClientDetails` brings its own caption and outer padding.
- The date is a `<time>`; the Figma format `07.23.2023` is only text — formatting is up to the caller.
- The clock icon is the existing `time-new` (round filled clock), chosen by look. Needs designer confirmation. Figma asset downloads were not used.

## Accessibility

- An `<article>`; "more" is a real `<button>`; the date is a `<time>`; the clock icon is decorative (`aria-hidden`).
- Contrast: Color Text on BG Color 13.8:1, Headlines on BG Color 7.3:1.
- Dark theme contrast: text `#C9C6D9` on `#101010` 11.38:1, “more” `#0AABDE` 7.15:1.
