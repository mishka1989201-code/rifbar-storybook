# Accordion

A full-width collapsible section header: a title and a chevron button. Implements the Figma component set [`Accordion`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=155-52780) (`Property 1` Static / Hover / Focus / Disabled).
The look follows `TableRowExpandable` (same card, hover fill, violet stroke when opened).

| `Property 1=Disabled` | `disabled` | `--opacity-disabled` (20%) |

| `button_action` + chevron | `.ds-accordion__toggle` | Secondary Light square, radius 5, `chevron-down` / `chevron-up` |

## When to use

- ✅ Grouping long content (filters, form sections, table blocks) under headers that open one at a time or independently.

## When NOT to use

- ❌ A short hint — use a tooltip. ❌ Navigation between pages — use `Tabs`.

## Figma notes

- Figma draws only the header (1524px wide). The panel (`children`) is **AI-defined**: 16px padding, Grey Dark Body/Small text.
- `Focus` in Figma has the up chevron, so it is mapped to `open`. Real keyboard focus is **AI-defined**: `--shadow-focus` on the header.
- The whole header is one button (Figma only shows the small square as a button) — bigger target, one tab stop. Hover is drawn on the whole card, as in Figma.
- Figma strokes are inside: drawn as an inset shadow. Shadow `0 4 2 / 5%` in Figma is read as the `Table Row` shadow (`0 4 4 / 5%`) — the style name matches.
- The toggle is 36px instead of 37px (no 10.5px token), as in `TableRowExpandable`. Dark theme not designed.

## Dark theme

Figma "Dark Molecules Components" → `Accordion Dark` (Static / Hover / Focus / Disabled): row `#000000` with a `#242424` stroke, title `#BDC5E2`, hover fill `#242424`, open (Focus) stroke `#888CF6`, toggle `#27282E`. **Open question:** the open title is drawn grey `#5D6E82` in dark (Headlines in light), which looks unadapted; copied as drawn. Story: `AllVariantsDark`.

## Accessibility

- The header is a native `<button aria-expanded aria-controls>`; Enter / Space toggle it.
- Disabled at 20% opacity is below 3:1 — kept as designed.
- The chevron square is 36px — below the 44px touch target, but the whole 62px-high header is clickable.
- Dark theme contrast: title 12.25:1; open title `#5D6E82` on `#000000` 4.02:1 (⚠️ below 4.5:1, as drawn).
