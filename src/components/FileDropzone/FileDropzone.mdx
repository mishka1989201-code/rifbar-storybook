# FileDropzone

A dashed area to drop files on or click to browse. Implements the Figma `Drag Files` frame of [`BarcodeSettings`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=7064-74791) (Information2).
A real `<input type="file">` is inside, so click, keyboard (Tab, Enter / Space) and drag-and-drop all work.

## When to use

- ✅ Uploading one or several files where dropping is convenient (barcodes, documents, images).

## When NOT to use

- ❌ A single button that just opens a picker — use `Button`.

## Figma notes

- Figma draws one state. **AI-defined:** hover and drag-over (solid Headlines border + BG Color fill), keyboard focus (`--shadow-focus`), disabled (20%).
- The upload icon is an unnamed raster/cloud asset; matched to the existing 24px `upload`, coloured Headlines. To be confirmed.
- File validation and upload are the parent's job: the component only reports files via `onFiles`.
- Dark theme not designed.

## Code example


## Accessibility

- The visible area is a `<label>` for the hidden file input, which stays focusable; focus draws the ring on the area.
- Dropping is a pointer-only convenience; Browse covers keyboard users.
- “Drag your files here” in Grey Dark on white passes 4.5:1; the dashed border (Headlines @ 40%) is below 3:1 — kept as designed.
- The 95px area is above the 44px touch target.
