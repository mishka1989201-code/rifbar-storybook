# BreadCrumbs

Shows where the user is in the page hierarchy and lets them go back up. Implements the Figma frame
[`Bread Crumbs`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=32-9619)
(root “Clients” + 4 crumbs; 1524px wide in the mockup, here 100% of the container).

## Figma → code mapping

| Figma | Code |
|---|---|
| First text (Grey Dark) | `items[0]` |
| Next texts (Primary Blue Dark) | `items[1..]` |
| `Icons 16px` Rifbar Small, Color=Secondary | separator, `<Icon name="rifbar-small" color="secondary">` |
| Frame `flex-wrap`, gap 16 / 4, padding-y 8 | `.ds-breadcrumbs__list` |
| 768px and below: `Icons 16px` chevron + one text (Primary Blue Dark) | `variant="back"`: `chevron-left` icon + the last item, linking to the previous item |

## When to use

- ✅ Pages two or more levels deep (Clients → All → …).

## When NOT to use

- ❌ Switching sections of one page — use [Tabs](?path=/docs/atoms-tabs--docs).

## Dark theme

Figma "Dark Molecules Components" → `Bread Crumbs Dark` / `Bread Crumbs Hover Dark`. Dark ≠ light: inner crumbs are Grey Dark `#5D6E82` (same as the root), only the current page is bright `#BDC5E2`; a hovered crumb turns `#888CF6`. Light theme is unchanged (inner crumbs Primary Blue Dark). **Question for the designer:** should the light theme also grey out the inner crumbs? Story: `DefaultDark`.

## Code example

```tsx
import { BreadCrumbs } from 'rifbar-ds';

<BreadCrumbs
  items={[
    { label: 'Clients', href: '/clients' },
    { label: 'All', href: '/clients/all' },
    { label: 'Acme Ltd.' },
  ]}
/>
```

## Accessibility

- `<nav aria-label="Breadcrumb">` with an ordered list; the last crumb has `aria-current="page"`.
- The separator icon is decorative (`aria-hidden`).
- Contrast: Grey Dark on White 5.2:1, Primary Blue Dark on White 15:1.
- Dark theme contrast (on `#000000`): Grey Dark 4.02:1 (⚠️ below 4.5:1 for 14px text, kept as designed), current `#BDC5E2` 12.25:1, hover `#888CF6` 7.13:1.
