# RadioGroupCard

A caption and a grey card with a row of radio options, e.g. “Integrations for invoices: Rifbar / QuickBooks”.
Implements the Figma frame [`Integrations for invoices`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=4078-332535). It is composed of the [Checkbox](?path=/docs/atoms-checkbox--docs) atom (`type="radio"`) in the same card as [AccessModeRow](?path=/docs/molecules-accessmoderow--docs).

## When to use

- ✅ Choosing one of a few short options inside a form or a settings panel (integration, mode, provider).

## When NOT to use

- ❌ Choosing between "Default" and "Custom" with an Edit button — use [AccessModeRow](?path=/docs/molecules-accessmoderow--docs). Many options — use a select.

## Figma notes

- Figma draws one frame (Rifbar chosen, QuickBooks unchosen) at 730px with 16px padding around the title and the card. The code has no outer padding (the container gives it) and is 100% wide.
- Radio ↔ label gap is 4px as in Figma; the `Checkbox` atom's own 8px gap is overridden inside this molecule only.
- Figma names the two radios `Custom` / `Default` (copies of the Edit User Access card); here the options are data (`options`), the names are not kept.
- Not designed, AI-defined: options wrap to the next line when the card is narrow (8px row gap); disabled = whole group at `--opacity-disabled`, single `disabled` option uses the atom's own disabled look; hover and focus come from the `Checkbox` atom. Dark theme not designed — light values are used.

## Accessibility

- Native radio inputs in one group (`name`), `role="radiogroup"` labelled by the title; arrow keys move the selection.
- Radio 16px with a text label — click target is the whole label, still below 44px; kept as designed.
- Disabled at 20% opacity is below 3:1 contrast — kept as designed. Grey Dark `#5D6E82` and Headlines `#4549A1` on `#F6F8FC` pass 4.5:1.
- Dark theme contrast (on `#101010`): chosen 6.46:1, other options `#5D6E82` 3.64:1 (⚠️ below 4.5:1, kept as designed).
