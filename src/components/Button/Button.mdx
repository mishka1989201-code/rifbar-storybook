# Button

Action button for the Rifbar ERP. Implements the Figma component set

| Figma property | Figma value | Prop |
|---|---|---|
| Style | Outline Light BG | `variant="outline"` |
| Style | Dark BG | `variant="dark"` |
| Style | Light Fill | `variant="light"` |
| Style | Red | `variant="danger"` |
| Style | Gray BG | `variant="gray"` |
| Style | Text & Arrow | `variant="text-arrow"` |
| Style | Text & Checkmarks | `variant="text-checkmarks"` |
| Size | Small / Medium / Big | `size="small" \| "medium" \| "big"` |
| Icon | Left | `iconLeft="…"` |
| Icon | Left & Right | `iconLeft` + `iconRight` or `counter` |
| Icon | Just Icon / Just Icon v2 | `iconOnly="…"` + `aria-label` |
| Icon | Icon 24px | `iconOnly="…"` + `iconSize={24}` + `aria-label` |
| Icon | No Icon | no icon props |
| Status | Static / Hover / Disabled | default / CSS `:hover` (`forceHover` for preview) / `disabled` |

## When to use

- ✅ **Dark BG** — the primary action of a screen or dialog (Export, Make a discount).
- ✅ **Outline Light BG / Light Fill** — secondary actions in toolbars and filters (Clear, More).
- ✅ **Red** — destructive actions (Reject, Delete) — pair with confirmation.
- ✅ **Gray BG** — navigation back to a previous step.
- ✅ **Text & Arrow / Text & Checkmarks** — inline, low-emphasis actions inside cards and lists.

## When NOT to use

- ❌ More than one Dark BG button in the same group.
- ❌ Red for anything that isn't destructive.
- ❌ Text buttons for primary actions — they have no hit area beyond the label.
- ❌ Icon-only buttons without `aria-label`.

## Dark theme

Figma frame **Dark Atoms Components → `button_actio_dark`**. No new component or props: the colours come from themed `--button-*` tokens
(light value = the previous value, so the light theme is unchanged). Switch the toolbar theme, or open **AllVariantsDark**.

| Variant | Dark fill | Dark text / stroke |
|---|---|---|
| `outline` | `#242424` (stroke `#242424`, so no visible border) | `#BDC5E2` |
| `dark` (text buttons) | `#050411` | `#BBC7D6` |
| `dark` with `size="big"` or `iconOnly` | `#BDC5E2` | `#000000` |
| `light` | `#27282E` | `#BDC5E2` |
| `danger` | `#ED5742` (solid, not the 60% Danger Fill) | `#000000` |
| `gray` | `#5D6E82` | `#000000` |
| `text-arrow` | – | `#BDC5E2`, hover `#888CF6` |
| `text-checkmarks` | – | `#888CF6`, hover `#4549A1` |

Hover is the same recipe as in the light theme (fill removed, stroke + text in `#BDC5E2`; Red in `#ED5742`). Disabled stays at 20% opacity.

**Figma dark notes:** Dark BG is not one colour in the dark frame: text buttons use Primary Blue Dark (Dark) `#050411`, while Big and Just Icon use Primary Blue Dark (Light) `#BDC5E2`
with black content. `text-arrow` / `text-checkmarks` hover colours and the counter badge are read from the render (Figma shows no variable). Focus ring is not designed in dark; the light ring `--color-headlines` is kept.

## Accessibility

- Native `<button>` with `type="button"` by default.
- `disabled` uses the native attribute.
- Icons are `aria-hidden`; icon-only buttons **must** pass `aria-label`.
- ⚠️ Touch target: Figma sets 37×37px (below the 44×44px guideline). Kept as designed — desktop ERP.
- ⚠️ Contrast: Red (`rgba(218,29,3,0.6)` on white ≈ 3:1 with white text) and the 20% disabled opacity are below 4.5:1 — flag to design.
- Dark theme contrast (calculated): Outline text 9.05:1, Dark BG 11.87:1, Dark BG Big 12.25:1, Light Fill 8.57:1, Red 6.04:1, Gray 4.02:1 (passes 3:1 for large/UI text, not 4.5:1 for 14px text — kept as designed),
  Text & Checkmarks hover `#4549A1` on black **2.72:1** (below 3:1), focus ring `#4549A1` on black 2.72:1 — flag to design.
