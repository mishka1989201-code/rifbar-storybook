# Button

Action button for the Rifbar ERP. Implements the Figma component set
[`button_action`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=17-5741)

## Figma → code mapping

| Figma property | Figma value | Prop |
|---|---|---|
| Style | Outline Light BG | `variant="outline"` |
| Style | Dark BG | `variant="dark"` |
| Style | Light Fill | `variant="light"` |
| Style | Red | `variant="danger"` |
| Style | Gray BG | `variant="gray"` |
| Style | Text & Arrow | `variant="text-arrow"` |
| Style | Text & Checkmarks | `variant="text-checkmarks"` |
| Size | Small / Medium / Big | `size="small" \| "medium" \| "big"` |
| Icon | Left | `iconLeft="…"` |
| Icon | Left & Right | `iconLeft` + `iconRight` or `counter` |
| Icon | Just Icon / Just Icon v2 / Icon 24px | `iconOnly="…"` + `aria-label` |
| Icon | No Icon | no icon props |
| Status | Static / Hover / Disabled | default / CSS `:hover` (`forceHover` for preview) / `disabled` |

## When to use

- ✅ **Dark BG** — the primary action of a screen or dialog (Export, Make a discount).
- ✅ **Outline Light BG / Light Fill** — secondary actions in toolbars and filters (Clear, More).
- ✅ **Red** — destructive actions (Reject, Delete) — pair with confirmation.
- ✅ **Gray BG** — navigation back to a previous step.
- ✅ **Text & Arrow / Text & Checkmarks** — inline, low-emphasis actions inside cards and lists.

## When NOT to use

- ❌ More than one Dark BG button in the same group.
- ❌ Red for anything that isn't destructive.
- ❌ Text buttons for primary actions — they have no hit area beyond the label.
- ❌ Icon-only buttons without `aria-label`.

## States

Figma defines **Static**, **Hover** and **Disabled**. Hover removes the fill and tints stroke, text and icon.
Disabled is the Static look at 20% opacity.

**Not designed in Figma:** Focus (AI-defined: 2px `--color-headlines` outline, 2px offset), Pressed and Loading.
Pressed currently reuses Hover; Loading is not implemented — ask design before adding it.

Empty state: not applicable — Button doesn't display data.

## Code example

```tsx
import { Button } from './components/Button';

<Button variant="dark" iconLeft="export" onClick={exportCsv}>Export</Button>
<Button variant="outline" iconLeft="clear" counter={2} onClick={clearFilters}>Clear</Button>
<Button variant="danger" size="big" onClick={confirmDelete}>Delete</Button>
<Button variant="dark" iconOnly="export" aria-label="Export" />
<Button variant="text-arrow">See all</Button>
```

## Accessibility

- Native `<button>` with `type="button"` by default.
- `disabled` uses the native attribute.
- Icons are `aria-hidden`; icon-only buttons **must** pass `aria-label`.
- ⚠️ Touch target: Figma sets 37×37px (below the 44×44px guideline). Kept as designed — desktop ERP.
- ⚠️ Contrast: Red (`rgba(218,29,3,0.6)` on white ≈ 3:1 with white text) and the 20% disabled opacity are below 4.5:1 — flag to design.
