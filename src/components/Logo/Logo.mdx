# Logo

The Rifbar logo: sign, RIFBAR wordmark and the “Renaissance of Vaping” tagline. Lives in the Navbar.
Implements the variant **V2 - Approved** of the Figma component set
[`Logo Rifbar Header Big`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=1018-23405).
V1 and V3 are not used.

## Figma → code mapping

| Figma | Prop |
|---|---|
| Property 1 = V2 - Approved, 184×46 | `<Logo />` (`size="lg"`) |
| Same logo at 1440px, 165×40 (Figma Grids) | `size="md"` |
| Same logo in the side menu below 1440px, 149×36 (Figma Navbar/Full) | `size="sm"` (`--size-logo-overlay-*`, new) |
| Fill Primary Blue Dark | `tone="default"` |
| — (not in Figma) | `tone="inverse"` — for the dark Navbar |

The SVG paths are exported from Figma; the logo is one color, drawn with `currentColor`.

## When to use

- ✅ In the Navbar / header of the app, once per screen.

## When NOT to use

- ❌ As a small app icon — use the `rifbar-small` / `rifbar` [Icon](?path=/docs/atoms-icon--docs).
- ❌ Don't stretch, recolor with other colors or rebuild it from text.

**Not designed in Figma:** `inverse` tone. AI-defined: the Navbar background is Primary Blue Dark, so the
Figma color would be invisible there. The logo uses `--theme-nav-text-active` — the same color as the active Navbar text.

## Design tokens used

| Token | Property | Value | Source |
|---|---|---|---|
| `--color-primary-blue-dark` | `default` color | `#1D2542` | Figma: Primary Blue Dark (color style) |

## Code example

```tsx
<Logo />
```

## Accessibility

- `role="img"` with `aria-label` “Rifbar” by default.
- Inside a link, give the link the name (“Rifbar — home”) and pass `title=""` so the name is not read twice.
- Contrast: Primary Blue Dark on White 15.0:1; White on the Navbar 15.0:1.
