# InfoClient

White block with label/value pairs — a client's summary. Implements the Figma component
[`InfoClient`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=4539-268692)
(`Direction=Line` and `Direction=Wrap`, 1290px wide in the mockup, here 100% of the container).

The two Figma variants differ only in how fields sit in the row, so they are **one flex component**: fields wrap
automatically and `justify` picks `space-between` (Line) or `flex-start` (Wrap).

## Figma → code mapping

| Figma | Code |
|---|---|
| `InfoClient` frame (White, padding 32/16) | `.ds-info-client` |
| `Direction=Line` (`justify-between`, row gap 16) | `justify="between"` (default) |
| `Direction=Wrap` (`gap 16 / 24`, packed left) | `justify="start"` |
| Field: caption “Name” (Mini Medium, Secondary Grey) | `fields[i].label` → `<dt>` |
| Field: value “Mickey Herman” (Semi-Bold h5, Color Text) | `fields[i].value` → `<dd>` |
| Gap caption ↔ value 2 | `--spacing-2` |

## When to use

- ✅ Summary of a client / order / document at the top of a details page.

## When NOT to use

- ❌ Editable forms — use input fields.
- ❌ Long key-value lists — use a table.

## Code example

```tsx
import { InfoClient } from 'rifbar-ds';

<InfoClient
  justify="start"
  fields={[
    { id: 'name', label: 'Name', value: 'Mickey Herman' },
    { id: 'country', label: 'Country', value: 'USA' },
  ]}
/>
```

## Accessibility

- Rendered as a description list (`<dl>`, `<dt>` label, `<dd>` value), so label/value pairs are announced together.
