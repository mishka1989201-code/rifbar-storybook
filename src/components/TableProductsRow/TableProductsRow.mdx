# TableProductsRow

Body row of the products table: white background, 1px bottom stroke. Implements the Figma frame
[`Table Products Row`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=78-26107)
(1524px wide in the mockup, here 100% of the container). Uses the same column grid as
[TableProductsHeader](?path=/docs/molecules-tableproductsheader--docs).

## When to use

- ✅ Each product line of the products table, under `TableProductsHeader`.

## When NOT to use

- ❌ Rows with actions, checkboxes or other column sets — build a separate row.
- ❌ Mobile layouts: cells have fixed widths.

## Code example

```tsx
import { TableProductsHeader, TableProductsRow } from 'rifbar-ds';

<div role="table">
  <TableProductsHeader />
  <TableProductsRow index={1} name="Astro" flavor="Malibu peach" type="DISPOSABLE" nicotine="5%" quantity={15} amount="$150" />
</div>
```

## Accessibility

- `role="row"` with `role="cell"` cells; place inside `role="table"` after a `TableProductsHeader`.
- Dark theme contrast: `#C9C6D9` on `#000000` 12.56:1.
