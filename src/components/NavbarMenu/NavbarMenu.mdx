# NavbarMenu

The vertical list of pages in the side menu. One tab is active (a filled bar), the others are plain text on the dark Navbar background.
Implements the Figma component set
[`Navbar Menu Tabs`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/%F0%9F%93%B1-ERP-System-v-1.1--Mockups----Rifbar-2023%F0%9F%93%B1?node-id=48-12836)
— 5 variants: Desktop, Icons and 360 / 480 / 768 px. They differ only in width, spacing and whether labels are shown,
so they are **one component** with `size` and `collapsed`.

## Figma → code mapping

| Figma | Code |
|---|---|
| `Style=On`, `Size=Desktop` | `size="desktop"` (default), width `--layout-sidebar-desktop-lg` (300px), gap 8 |
| `Style=Icons` | `collapsed`, width `--layout-sidebar-desktop-lg-collapsed` (108px), labels hidden |
| `Style=On`, `Size=768px` / `480px` | `size="768"` / `size="480"`, width `--layout-sidebar-overlay` (253px), gap 16 |
| `Style=On`, `Size=360px` | `size="360"`: as 480 + tabs above Tickets are indented 26px (`secondary` tabs keep 32px) |
| `Tab 1` (Hover Blue fill, white Medium) | tab with `value === id` (`is-active`) |
| `Tab 2…10` (Not Active, Regular) | other tabs |
| `Tab 5 Title`, `Product Settings` + chevron | `expandable: true` |
| `Subtabs` (Admin, Reports, Product Settings) | `children` of an `expanded` item; `value` can be a sub-tab id |
| `Size=1440px` / `1024px` (Navbar/Full) | `size="1440"` (237px, 16px padding, collapsed 81px) / `size="1024"` (253px, gap 8) |
| `Icons 16px` | `icon` (16px set) |

## When to use

- ✅ The main page list of the side menu (desktop, collapsed and the slide-over menu on narrow screens).

## When NOT to use

- ❌ Switching content inside a page — use [TabsHeader](?path=/docs/molecules-tabsheader--docs).
- ❌ Icons in the page header — use `HeaderMenu`.

## Figma notes

What Figma draws: the active tab, the closed chevrons, the five sizes above.

Not drawn, defined by analogy (AI-defined):

- **Hover** — label and icon turn `--theme-nav-subtab-active` (Hover Blue Light), as the Switcher and the burger in `LogoBar`.
- **Focus** — 2px `--theme-nav-subtab-active` outline drawn inside the tab (the menu is clipped by its parent).
- **Disabled** — 20% opacity (`--opacity-disabled`).
- **Expanded** — chevron up (`chevron-up`); Figma only shows chevron down.
- **Long labels** — ellipsis; **empty list** — renders nothing.
- **Dark theme** — colors come from the existing `--theme-nav-*` tokens (dark values already defined there).

Normalised or assumed:

- Figma tab frames are 300 / 253 / 108px wide but their parent frames are narrower (268 / 221 / 76px) and clip the tabs. The tab widths (the `--layout-sidebar-*` tokens) are used.
- The chevron of an expandable tab follows its label after the 8px gap. Figma puts it 8px after the label for *Reports & Analytics*, 28px after for *Product Settings* (Desktop, 480, 768) and at the right edge for *Product Settings* in 360 — these were three different values for one thing.
- The tab height is fixed at 32px (`--size-nav-tab`); Figma's 8px vertical padding plus a 21px line would be 37px.
- 360px: the first six tabs have 26px left padding, the last four 32px — kept as designed through `secondary` (looks like a Figma slip, needs confirmation).
- Icons are unnamed vectors in Figma and are matched by look: `user`, `cart`, `call`, `order`, `graph`, `product-box`, `ticket`, `notes`, `email`, `groups`, `chevron-down`. Needs designer confirmation.
- Figma asset downloads were not used; icons are the existing `Icon` set.

## Dark theme

Figma "Dark Molecules Components" → `Navbar menu tabs Dark` / `Navbar Tabs Dark`: colours come from the existing `--theme-nav-*` tokens (menu on `#050411`, active tab `#4549A1`); nothing changed. In the story the menu is drawn on the story background (`#000000`) instead of the Navbar surface. Story: `AllVariantsDark`.

## Code example

```tsx
import { NavbarMenu } from 'rifbar-ds';

<NavbarMenu
  aria-label="Main menu"
  value={page}
  onChange={setPage}
  items={[
    { id: 'clients', label: 'Clients', icon: 'user' },
    { id: 'orders', label: 'Orders', icon: 'order' },
    { id: 'reports', label: 'Reports & Analytics', icon: 'graph', expandable: true },
  ]}
/>
```

Put it on the Navbar background (`--theme-app-bg`): the colors are made for it.

## Accessibility

- A `<nav>` landmark with `aria-label`, a list of buttons; the active one has `aria-current="page"`, expandable ones `aria-expanded`.
- Collapsed: labels are not drawn but stay as `aria-label` and `title` of each button.
- ⚠️ Kept as designed: Not Active `#D2D3D9` on the dark Navbar is readable, but the 32px tab height is below the 44px touch target.
- ⚠️ Disabled at 20% opacity is below 3:1 contrast.
