# NoRowsTable

The placeholder of a table that has no rows: a pale chart (grid, axis numbers) with the Rifbar sign as a watermark and the text
“Table has no rows” over it. Implements the Figma component set
[`No Rows table`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/%F0%9F%93%B1-ERP-System-v-1.1--Mockups----Rifbar-2023%F0%9F%93%B1?node-id=4319-33338)
(3 sizes × light / dark). The sign comes from [Logo](?path=/docs/atoms-logo--docs).

## When to use

- ✅ The body of a table (clients, orders, products) when the filtered or loaded list is empty.

## When NOT to use

- ❌ A table that is loading or failed — show a loading or an error message instead (see [TableClients](?path=/docs/organisms-tableclients--docs) `status`).
- ❌ Lists that are not tables — use their own empty message.

## Figma notes

What Figma draws: the three sizes in both themes. All sizes are one drawing scaled (aspect 495 : 328, text and numbers scale with it).
Nothing else is drawn: no hover, no focus, no action. The component is a static picture.

- The drawing is vectors that could not be downloaded (asset proxy 403), so it is redrawn as inline SVG from measurements of the Figma render
  (grid 21 columns × 5 rows, step 20.6 / 45.4px, axis at y=264.5, numbers 12px, title 39.4px Poppins Medium). Compared with the render by eye: no pixel diff.
- Grid and axis colours have no variable in Figma; they were read from the render and need confirmation (grid = Secondary Grey @ 15% light / 25% dark,
  axis and numbers = @ 75% / 50%).
- The watermark is White in the light theme and White (Dark) in the dark one, drawn under the grid lines (as in Figma).
- Corner radius: `--radius-lg` (10px) in every size; Figma looks the same, not measured per size.
- `label`: Figma has only “Table has no rows”. A custom text is AI-defined; the title keeps its size relative to the card, so a long label overflows the grid.
- Not tied to a table yet: `TableClients` / `TableOrders` still show their text message for an empty list. Use `NoRowsTable` in place of it where the Figma screen asks for it.

## Accessibility

- The card is `role="status"`; the drawing is `aria-hidden`, and the label is announced once from a visually hidden copy.
- Contrast, computed: title `#A7A4B7` on `#F6F8FC` 2.29:1, dark `#646464` on `#101010` 3.22:1.
- ⚠️ Kept as designed: the title is below 4.5:1 (and below 3:1 in the light theme), and the axis numbers (1.81:1, dark 1.67:1) are decorative and hidden from
  screen readers; the card against the `#F5F5F5` page is 1.03:1 (separated by the thin stroke only).
- No interactive element, so no touch-target issue.
