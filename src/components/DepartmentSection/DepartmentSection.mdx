# DepartmentSection

Section of a ticket / details panel: a title with a "Change" dropdown pill, a grey hint and a bottom divider.
Implements the Figma component [`Section.Department`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=139-47444) (368px wide in the mockup, here 100% of the container).
Composes the existing atom [ChevronDropDown](?path=/docs/atoms-chevrondropdown--docs). Title, hint and pill label are props, so the same
component serves other sections ("Priority", "Assignee"…).

## When to use

- ✅ A details-panel row where a single value (department, priority, assignee) can be changed from a list.

## When NOT to use

- ❌ A full form field with an input — use [InputField](?path=/docs/atoms-inputfield--docs).

## Figma notes

- The hidden `Department` instance (the opened list) is not visible in Figma, so the list is not part of this molecule.
- Open and Disabled states of the pill come from `ChevronDropDown` (AI-defined by analogy there).
- Long title / hint are not designed. AI-defined: title is truncated with an ellipsis, the hint wraps.
- Dark theme not designed — light values are used.

## Accessibility

- The pill is a `<button aria-haspopup aria-expanded>` (from `ChevronDropDown`); give it an `aria-label` such as "Change department" via `actionProps`, because "Change" alone is not descriptive.
- Hint #5D6E82 on white is about 5:1 — passes. The 26px pill is below the 44px touch target (kept as designed).
