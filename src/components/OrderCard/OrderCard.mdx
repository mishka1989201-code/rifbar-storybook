# OrderCard

Document card: title with a button, a document preview and label/value rows. Implements the Figma [`Card`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=7038-332399) Property 2=Order. Status values use [ChevronStatus](?path=/docs/atoms-chevronstatus--docs).

| `image 423` 204×204, radius 10 | `preview` |
| `Card Stroke 1–4` (Mini Semi-Bold) | `fields` (value can be a `ChevronStatus`) |

## When to use

- ✅ Order / invoice summary with a document thumbnail.

## When NOT to use

- ❌ Plain label/value blocks without a preview — use `InfoBlock`.

## Dark theme

Figma "Dark Molecules Components" → `Order Card Dark`: card `#000000`, stroke `#242424`, labels `#888CF6`, title and values `#C9C6D9`; the chevron button and the status pill come from the atoms. Story: `DefaultDark`.

`object-position: top` on the preview approximates the Figma crop (needs confirmation). Icon `chevron-down` in the button matches Figma.

## Code example

```tsx
import { OrderCard, Button, ChevronStatus } from 'rifbar-ds';

<OrderCard
  title="Order #4645"
  action={<Button variant="light" iconOnly="chevron-down" aria-label="Expand" />}
  preview={url}
  fields={[{ id: 'status', label: 'Status:', value: <ChevronStatus color="light">Awaiting payment</ChevronStatus> }]}
/>
```

## Accessibility

- Icon-only `action` needs `aria-label`; give the preview an `previewAlt`.
- Underlined values are plain text, not links.
- Dark theme contrast: labels 7.13:1, text 12.56:1.
