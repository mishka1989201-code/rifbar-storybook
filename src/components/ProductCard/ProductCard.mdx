# ProductCard

Product tile: photo with badge and checkbox, name, spec rows and a big button. Implements the Figma [`Card`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=7038-332399) Property 2=Category. Composes [Checkbox](?path=/docs/atoms-checkbox--docs) and [Button](?path=/docs/atoms-button--docs) (passed as `action`).

## When to use

- ✅ Product grid on mobile/tablet.

## When NOT to use

- ❌ Compact list rows — use `CardRow`.

## Dark theme

Figma "Dark Molecules Components" → `Category Card Dark`: card `#000000`, stroke `#242424`, title / labels / price badge `#888CF6` (badge text `#000000`), subtitle and values `#C9C6D9`. In the frame the “Edit” / “Details” buttons are near-black (`#27282E` / `#050411` with a stroke); the code leaves the action slot to the story (`Button` atom). Story: `DefaultDark`.

## Code example

```tsx
import { ProductCard, Button } from 'rifbar-ds';

<ProductCard
  image={url}
  title="Astro"
  badge="$25"
  specs={[{ id: 'colors', label: 'Colors:', value: '8' }]}
  action={<Button variant="dark" size="big">More info</Button>}
/>
```

## Accessibility

- Give the photo a meaningful `imageAlt`; the checkbox needs `checkboxProps={{ 'aria-label': … }}`.
- Rendered as an `<article>` with an `<h3>`; specs are a description list.
- Dark theme contrast: accent `#888CF6` on `#000000` 7.13:1, badge text 7.13:1, text 12.56:1.
