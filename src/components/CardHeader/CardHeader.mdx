# CardHeader

Title row at the top of a card or form section: round icon badge and a heading. Implements the Figma frame
[`Row.HeaderCard`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=32-10560)
(1290px wide in the mockup, here 100% of the container).

## Figma → code mapping

| Figma | Code |
|---|---|
| Frame `Row.HeaderCard` (White, padding 16, gap 8, bottom stroke Secondary Light) | `.ds-card-header` |
| `Ellipse 42` 26px, light blue fill | `.ds-card-header__badge` |
| `Icons 16px` person in the ellipse | `<Icon name="user">` via `icon` |
| “Client info” (Semi-Bold h5, Headlines) | `title`, rendered as `<h3>` |
| `Row.HeaderCard` in `scheduled-call-menu` (orange / green badge) | `tone="warning"` / `tone="success"` — see [ScheduledCallCard](?path=/docs/organisms-scheduledcallcard--docs) |

## When to use

- ✅ Header of an info card or form block, above its fields.

## When NOT to use

- ❌ Page titles — use the page heading.
- ❌ Table headers — use `TableHeader`.

## Dark theme

Figma "Dark Molecules Components" → `head Card Dark`: bar `#000000`, title `#888CF6`, badge glyph `#0AABDE` (Blue Light; in light it is Headlines). The `violet` tone (Ticket Info) is drawn **blue** in the dark frame (`#022631` ellipse, `#0AABDE` glyph) — copied as drawn. **Question for the designer:** is the blue ticket badge intended in dark, or should it stay violet? The standalone header line (`#242424`) is AI-defined. Story: `DefaultDark`.

## Accessibility

- The title is an `<h3>`; adjust the level in your page structure if needed.
- The badge icon is decorative (`aria-hidden`).
- Dark theme contrast: title `#888CF6` on `#000000` 7.13:1; badge glyph `#0AABDE` on `#022631` 5.96:1.
