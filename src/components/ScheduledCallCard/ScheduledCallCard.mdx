# ScheduledCallCard

A card for the next planned call with a client: a header with a phone badge, the date and time of the call as a field with a calendar icon, and a *Refresh* button.
Implements the Figma component set [`scheduled-call-menu`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/%F0%9F%93%B1-ERP-System-v-1.1--Mockups----Rifbar-2023%F0%9F%93%B1?node-id=3896-260429) — 2 variants (`Property 1` Static / Time to call). It is an **organism** built from
[CardHeader](?path=/docs/molecules-cardheader--docs), [FilterField](?path=/docs/atoms-inputfield--docs) (new `icon` prop) and [Button](?path=/docs/atoms-button--docs).

## When to use

- ✅ A client card or a call queue where the next call is planned and shown as due when its time comes.

## When NOT to use

- ❌ Picking a date for a form field — use `FilterField` / `InputField` with a [DatePicker](?path=/docs/organisms-datepicker--docs).
- ❌ A general status banner — use [AlertRow](?path=/docs/molecules-alertrow--docs) or [Notification](?path=/docs/molecules-notification--docs).

## Figma notes

What Figma draws: two cards with identical content; they differ in the card fill and border and in the badge color (orange / green).

Not drawn, defined by analogy (AI-defined):

- **Empty date** — the placeholder of `FilterField`; **no button, long title, narrow container** — the button drops under the field; the title is cut with an ellipsis.
- **Hover / focus** of the field and the button — from `FilterField` and `Button`. **Dark theme** — designed in `scheduled-call-menu-dark`; see the Dark theme section.
- **When a call becomes “due”** — the component only shows the state; the page decides (a timer, the server).

Normalised or assumed:

- The date field is a button that opens a calendar (`aria-haspopup="dialog"`); the calendar itself is the page's [DatePicker](?path=/docs/organisms-datepicker--docs).
- **Field look (open question 1):** Figma draws the field with Stroke Input `#8A87A0` and Grey Dark text although it holds a value; the `FilterField` atom draws a filled field with the Input field border and Color Text (`Activated`). The atom wins.
- The badge fills are read from the render (the SVG asset was not downloaded): Warning and Green Light at 22%, like the other badge tints (`--color-warning-tint` is new; `--color-green-light-tint` existed) — **needs confirmation**.
- Figma's header line is Stroke Light V2 on the card fill; `CardHeader` draws a Secondary Light line on white, so the card overrides both.
- The refresh icon is matched by look (`reboot`) — **needs designer confirmation**.

## Dark theme

Figma `Dark Organisms Components` → `scheduled-call-menu-dark` (3911:231908): `Static` and `Time to call`. Card fill `#000000`, stroke and header line `#242424`; `Time to call` fill `#1B0A00` (`warning-bg-dark`) with the same Warning 30% border as light (renders `#5D321A`); label `#A7A4B7` (the light value is kept), date field and `Refresh` come from `FilterField` / `Button` dark. Story `All variants (dark theme)`. Open questions for the designer: the `Static` badge is **green** in the dark frame (orange in light) — the code follows the frame through `--scheduled-call-card-badge-*`; the date field is drawn with a `#242424` border and `#646464` text, while the code shows the filled `FilterField` (bright text, active border). No shadow is drawn in dark: `--shadow-dark-1` is used (AI-defined).

## Accessibility

- A `section` with the title as its heading; the caption and the date field are one `label`, so the field is named “Date - Time”; the field is a native button, the *Refresh* button too.
- The two states differ in color only; the page should also say that the call is due in text (for example in the title).
- Contrast (calculated): title Headlines `#4549A1` 7.72:1 on white, 7.19:1 on Warning BG; field text `#5D6E82` 5.23:1 (Color Text 13.68:1 on Warning BG); Stroke Input border 3.47:1 / 3.23:1; button text on Secondary Light 13.03:1.
- ⚠️ Kept as designed: the caption (Secondary Grey) is **2.43:1** on white and 2.27:1 on Warning BG; the phone icon in its badge is **1.95:1** (warning) and **1.60:1** (success); the card border (Stroke Light V1) is 1.12:1; the 37px button and the 32px field are below the 44px touch target.
- Dark theme contrast, computed: label `#A7A4B7` on `#000000` 8.64:1; date placeholder `#646464` on black 3.55:1 and on `#1B0A00` 3.26:1 (below 4.5:1); card stroke / line `#242424` on black 1.35:1 (kept as designed).
