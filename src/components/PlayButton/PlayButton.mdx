# PlayButton

Round 38px button that starts (Play) or stops (Stop) something — e.g. playback of a call
recording or a timer. Implements the Figma component set
[`Button.Play`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=657-268619)
— 2 types × 3 statuses.

## Figma → code mapping

| Figma property | Figma value | Prop |
|---|---|---|
| Type | Play | `kind="play"` — light green tint circle, dark green triangle |
| Type | Stop | `kind="stop"` — red circle with shadow, white square |
| Status | Static | default |
| Status | Static Hover | CSS `:hover` (`forceHover` for preview) |
| Status | Disabled | `disabled` |

## When to use

- ✅ Start / stop playback or a running process with a single round control.
- ✅ Swap `kind` from `play` to `stop` while the process runs (see the toggle example).

## When NOT to use

- ❌ Pause — there's no Pause type in Figma. Ask design before reusing Stop for it.
- ❌ Generic actions with a text label — use [Button](?path=/docs/atoms-button--docs).
- ❌ Other icon-only actions — use [IconButton](?path=/docs/atoms-iconbutton--docs) or Button `iconOnly`.

## Dark theme

Figma frame **Dark Atoms Components → `Play`**: themed `--play-button-*` tokens, light values unchanged. See **AllVariantsDark**.

- Play: 22% green tint fill (unchanged, `#072E0F` on black), glyph and hover ring **Green Light `#1FD246`** (the light theme keeps Green Dark `#00864E` for contrast).
- Stop: fill `#ED5742`, square `#000000` (White (Dark)), hover ring and square `#ED5742`; the red drop shadow is unchanged.
- Pressed (not designed): accent fill, glyph `#000000` — AI-defined by analogy with Stop.

## Code example

```tsx
<PlayButton kind={playing ? 'stop' : 'play'} onClick={() => setPlaying(!playing)} />

```

## Accessibility

- Native `<button>` with `type="button"` by default.
- Default `aria-label`: “Play” / “Stop” — override with your own `aria-label` (e.g. Ukrainian copy, “Прослухати запис”).
- ⚠️ Touch target: 38×38 px (below 44×44). Kept as designed — desktop ERP.
- ⚠️ Disabled at 20% opacity is below 3:1 contrast — flag to design (same as Button).
- Play triangle uses Green Dark `#00864E`: 3.9:1 on the light tint, 4.2:1 on the canvas (≥ 3:1 for UI graphics).
  Green Light `#1FD246` was only 1.7:1, so it was replaced.
- Dark theme contrast (calculated): Play glyph `#1FD246` on its tint 7.37:1; Stop square `#000000` on `#ED5742` 6.04:1.
