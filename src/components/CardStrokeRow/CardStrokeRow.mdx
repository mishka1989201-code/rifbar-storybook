# CardStrokeRow

One line inside a card: a caption on the left and a value on the right. Implements the Figma component
[`Row.CardStroke`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=68-24983) (298px wide in the mockup, here 100% of the container).

## Figma → code mapping

| Figma | Code |
|---|---|
| Frame `Row.CardStroke` (flex, space-between, padding 0 16) | `.ds-card-stroke-row` |
| Text "Colors:" | `label` |
| Frame `Frame 427320358` → text "8" (right aligned) | `value` |
| Hidden instance `Icons 16px` inside the value frame | not drawn — put an `<Icon>` into `value` |

## When to use

- ✅ Short spec lines in a card: "Colors: 8", "Sizes: S, M, L".

## When NOT to use

- ❌ Several label/value pairs with a caption above the value — use [InfoClient](?path=/docs/molecules-infoclient--docs).

## Figma notes

- The name says "CardStroke" but the standalone frame has no stroke or fill of its own: the card border comes from the parent (e.g. `ProductCard`).
- Long label/value are not designed. AI-defined: the label is truncated with an ellipsis, the value stays on one line (max 60% of the row).
- The 8px gap between label and value is AI-defined (Figma has none, the two are pushed apart).

## Accessibility

- Plain text in a `div`; text color #292639 on white has high contrast. If the rows form a list of facts, wrap them in your own `<dl>`/`role="list"`.
