# UserDropdown

The user block of a header: avatar, name and a chevron — a button that opens a user menu.
Implements the Figma component [`user`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=48-10504). Composes the [Avatar](?path=/docs/atoms-avatar--docs)
(`variant="user"`) and [Icon](?path=/docs/atoms-icon--docs) atoms. Only the trigger; the menu is rendered by the parent.

## When to use

- ✅ The user name in the header that opens profile / sign-out.

## When NOT to use

- ❌ A static name without a menu — use `Avatar` + text.

## Figma notes

- Figma draws only the static state. AI-defined: Open (chevron-up, `aria-expanded`), Focus (`--shadow-focus`), Disabled (`--opacity-disabled`), hover underline (skipped under reduced motion).
- Long name is not designed. AI-defined: truncated with an ellipsis.
- Dark theme not designed — light values are used.

## Accessibility

- `<button aria-haspopup aria-expanded>`; the accessible name is the user name (the avatar is hidden from screen readers).
- Name #1D2542 on white has high contrast. The 32px target is below 44px (kept as designed).
