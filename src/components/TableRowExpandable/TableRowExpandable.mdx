# TableRowExpandable

A card-like row of the products table: number, photo, name, size, type, nicotine, price and a toggle button that opens the row.
Implements the Figma [`Table Row`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=1364-429592) set (`Style` Static / Hover / Active / Disabled).

## Figma → code mapping

| Figma | Code | Notes |
|---|---|---|
| `Style=Static` | default | White, Stroke Light V1, Table Row shadow |
| `Style=Hover` | `:hover` / `forceHover` | Row Hover fill, violet-tinted shadow, stroke on the button |
| `Style=Active` | `expanded` | White, Headlines stroke, toggle shows the **down** chevron |
| `Style=Disabled` | `disabled` | `--opacity-disabled` (20%), toggle disabled |
| `imageCards` 64px | `ImageCard size="md"` | composed, `image` prop |
| `button_action` | `.ds-table-row-expandable__toggle` | native `<button>`, `aria-expanded` |

## When to use

- ✅ Expandable product lines in a table drawn as separate cards.

## When NOT to use

- ❌ Flat rows with a bottom line — use [TableProductsRow](?path=/docs/molecules-tableproductsrow--docs). Narrow screens — use [TableRowMobile](?path=/docs/molecules-tablerowmobile--docs).

## Figma notes

- Figma draws the row at 1492px with fixed columns (318 / 125 / 203 / 75 / 52 / 54); in code the row is 100% wide and the columns keep these widths. It does not reflow below ~900px — use `TableRowMobile` there.
- Figma draws the **down** chevron on `Active` and **up** on the others. Kept as designed (`expanded` → `chevron-down`); the meaning (up = collapse?) should be confirmed by a designer.
- The photo in Figma is a product picture; in code it is the `image` prop (without it `ImageCard` shows its placeholder).
- The button is 36px (10px padding) instead of Figma's 37px (10.5px padding): there is no 10.5 token.
- The Hover stroke on `Style=Hover` is `#F1F2F9`, same as Static, so it is not visible against the row; kept as drawn.
- Not designed, AI-defined: Focus ring of the toggle (`--shadow-focus`), ellipsis for long `name` / `type`, transitions with `prefers-reduced-motion`, `pointer-events: none` on disabled. Dark theme not designed — light values are used.

## Code example

```tsx
import { TableRowExpandable } from 'rifbar-ds';

<TableRowExpandable
  index={1}
  image="/astro.png"
  name="Astro"
  size="15 ml"
  type="RECHARGEABLE / DISPOSABLE"
  nicotine="5%"
  price="$15"
  expanded={open}
  onToggle={() => setOpen(!open)}
/>
```

## Accessibility

- The toggle is a real `<button>` with `aria-expanded` and `aria-label`; the row has `role="row"` (wrap rows in `role="table"`).
- Toggle button is 36px — below the 44px touch target, kept as designed.
- Disabled at 20% opacity is below 3:1 contrast — kept as designed.
