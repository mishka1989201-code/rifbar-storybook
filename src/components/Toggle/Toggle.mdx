# Toggle

On / off switch for a setting that takes effect immediately. Implements the Figma component set
[`Toggle.atom`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=1685-19822)
— 2 states × 4 statuses.

## Figma → code mapping

| Figma property | Figma value | Prop |
|---|---|---|
| State | On State | `checked` / `defaultChecked` = `true` |
| State | Off State | `checked` / `defaultChecked` = `false` |
| Status | Enabled | default |
| Status | Hover | CSS `:hover` (`forceHover` for preview) |
| Status | Focus Enabled | CSS `:focus-visible` (`forceFocus` for preview) |
| Status | Disabled | `disabled` |

## When to use

- ✅ A setting that applies right away (notifications on/off, show archived items).
- ✅ In settings lists, table rows, side panels.

## When NOT to use

- ❌ Choices that are saved only with a “Save” button — use [Checkbox](?path=/docs/atoms-checkbox--docs).
- ❌ Picking one option from several — use radio buttons.
- ❌ Switching the light / dark theme — use [Switcher](?path=/docs/atoms-switcher--docs).

## Code example

```tsx
import { Toggle } from 'rifbar-ds';

<Toggle checked={enabled} onChange={(e) => setEnabled(e.target.checked)}>
  Email notifications
</Toggle>

<Toggle defaultChecked aria-label="Show archived" />
```

## Accessibility

- Native `<input type="checkbox" role="switch">` — Space toggles it, screen readers announce “switch, on/off”.
- Without a label, pass `aria-label`.
- ⚠️ Touch target: 48×24 px (height below 44px). Kept as designed — desktop ERP.
- White handle contrast: 5.2:1 on Grey Dark (Off), 6.4:1 on Input field (Off hover), 7.7:1 on Headlines (On).
- ⚠️ Disabled at 20% opacity is below 3:1 contrast — flag to design (same as Button).
