# Pagination

Page switcher for tables and lists. From the Figma component
[`Pagination`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=6294-253370)
— 2 versions. It is built from [IconButton](?path=/docs/atoms-iconbutton--docs)
(`page`, `prev`, `next`) inside a `<nav>`.

## Figma → code mapping

| Figma | What it means | In code |
|---|---|---|
| `Version=1` | Short list: `< 1 2 3 >` | `pageCount={3}` (any list that fits, no gaps) |
| `Version=2` | Long list: `< 1 2 3 4 5 6 ... 14 >` | `pageCount={14}`, `page={4}` |
| `Icon Button=Pagination Number`, `Status=Static` | Other page | IconButton `page` |
| `Icon Button=Pagination Number`, `Status=Active` | Current page | IconButton `page` + `active` (`aria-current="page"`) |
| `Pagination Arrow Left / Right` | Previous / next page | IconButton `prev` / `next` |
| `...` | Skipped pages | not interactive |

## When to use

- ✅ Long tables and lists split into pages.

## When NOT to use

- ❌ Few steps in a flow — use [Tabs](?path=/docs/atoms-tabs--docs).
- ❌ One page only — hide the component.

## Which pages are shown

Up to 7 pages are shown in full. More than that: the first and last page are always shown, the current page has 2 pages on each side (`siblingCount`), the rest is `...`. Near the start or end one block of 6 pages is shown, so the width does not jump (as in Figma, `1 2 3 4 5 6 ... 14`).

## Responsive: v1, v2 and the small size

Figma `Pagination Responsive` draws two proposals at 768 / 480 / 360px: **v1** keeps `1 2 3 4 5 6 … 14` (`siblingCount={2}`, the default), **v2** is shorter, `1 … 4 5 6 … 14` (`siblingCount={1}`). At 480px and below the buttons are 24px with 10px numbers (`size="sm"`) and spread over the container width.

**Figma notes:**
- Figma draws the arrows as the text `<` and `>`; IconButton does the same.
- The `...` is a 40×40 box with the text at the bottom, no fill (as in Figma). It is hidden from screen readers.
- Disabled arrows are not drawn in Figma; they use IconButton Disabled (20% opacity).
- Hover and focus come from IconButton.
- `size="sm"`: 24px buttons (Body/Micro Medium), `space-between` over the container; the `...` box is 24×24. Which width switches the size is the page's decision (the prototypes use 480px).
- **Needs designer confirmation:** v1 or v2. Both are implemented (`siblingCount`), the default stays v1.

## Dark theme

Figma frame **Dark Atoms Components → `Pagination Dark`** (`<` 1 2 3 `>`): the buttons are `IconButton`, so the dark colours come from its `--icon-button-*` tokens
(fill `#27282E`, active page `#050411` with `#BBC7D6` text, text `#BDC5E2`). The "..." gap uses `--icon-button-text`. See **AllVersionsDark**.


## Accessibility

- `<nav aria-label>` is a navigation landmark; change the name if there are several paginations on a page.
- The current page has `aria-current="page"`; arrows have `Previous page` / `Next page` labels.
- ⚠️ Buttons are 40×40px, slightly below the 44px touch target — kept as designed.
- ⚠️ Disabled arrows at 20% opacity are below 3:1 contrast (same as other components).
- Dark theme: same contrasts as IconButton (8.57:1 text, 11.87:1 active page).
