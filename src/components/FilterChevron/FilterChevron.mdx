# FilterChevron

An applied filter shown above a list or a table: **“Status: Primary ×”**. The × removes the filter.
Implements the Figma component set
[`Filter Chevron`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=746-387100)
— 3 styles + hover.

|---|---|---|---|---|
| Outline | `variant="outline"` | Stroke Light V1 | Secondary Grey | Grey Dark / Headlines |
| Outline Hover | `outline` on mouse hover | Secondary Light | Grey Dark | Grey Dark / Headlines |
| Outline V2 | `variant="outline-v2"` | Stroke Light V1 | Headlines | Grey Dark / Headlines |
| Filled | `variant="filled"` | Headlines | — | Not Active / White |
| “Status” text | `label` | | | Body/Mini Medium |
| “Primary” text | `children` | | | Body/Mini Semi-Bold |
| × icon | `onRemove` | | | `xmark` at 12px, same color as the value |

## When to use

- ✅ Showing which filters are applied to a table or list, so they can be removed one by one.
- ✅ One chip per filter: `label` = filter name, `children` = chosen value.

## When NOT to use

- ❌ The status of a row or an item — use [ChevronStatus](?path=/docs/atoms-chevronstatus--docs).
- ❌ Choosing a filter value — use a filter field ([InputField](?path=/docs/atoms-inputfield--docs)) or a dropdown.
- ❌ Switching between views — use [SwitchButton](?path=/docs/atoms-switchbutton--docs) or [Tabs](?path=/docs/atoms-tabs--docs).

## Code example

```tsx
import { FilterChevron } from 'rifbar-ds';

<FilterChevron label="Status" onRemove={() => removeFilter('status')} removeLabel="Remove filter Status: Paid">
  Paid
</FilterChevron>

<FilterChevron variant="filled" label="Client" onRemove={…}>Lviv Coffee</FilterChevron>
```

## Accessibility

- × is a real `<button>`: reachable with Tab, works with Enter / Space.
- Pass a full `removeLabel` (“Remove filter Status: Paid”) — with several chips, “Remove filter” alone is ambiguous.
- After a chip is removed, move focus to the next chip or to the filter field so keyboard users don't lose their place
  (the app decides where).
- Contrast of the text (12px needs 4.5:1):

| Style | Label | Value | |
|---|---|---|---|
| Outline | 4.7:1 | 6.9:1 | ✅ |
| Outline Hover | 4.5:1 | 6.7:1 | ✅ |
| Outline V2 | 4.7:1 | 6.9:1 | ✅ |
| Filled | 5.2:1 | 7.7:1 | ✅ |

- The Secondary Grey stroke of Outline is 2.2:1 — fine, because the text, not the border, identifies the chip.
- Dark theme contrast (calculated): value `#888CF6` on `#242424` 5.27:1; ⚠️ label `#5D6E82` on `#242424` **2.97:1**, Hover value `#4549A1` on `#27282E` **1.90:1** — as designed, flag to design. Stroke `#646464` on black 3.55:1.
