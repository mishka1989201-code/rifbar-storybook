# TableRowMobile

A compact table row for narrow screens: a caption, a centered value, a right-aligned value and a full-width action button.
Implements the Figma component set [`TableRow`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=7047-352588) (`Property 1` = 360px / 480px — one component with a `size` prop).
Composes the [Button](?path=/docs/atoms-button--docs) atom (`variant="dark"`, `iconLeft="edit"`).
For the wide products table see [TableProductsRow](?path=/docs/molecules-tableproductsrow--docs).

## When to use

- ✅ A table on a phone: each record is a row with 3 key values and one action.

## When NOT to use

- ❌ Wide desktop tables — use [TableProductsRow](?path=/docs/molecules-tableproductsrow--docs). Cards with images and many fields — use `CardRow`.

## Figma notes

- The two Figma variants differ only in width (320 / 416) and the button padding (8 / 12 × 8). In code the row is always 100% of its container; `size` switches only the button height.
- The cell widths in Figma (50 / 100 / 40px) are fixed boxes; in code the first and last cells hug their content and the middle one takes the rest and is centered — the same positions.
- The Figma cell names are "Header with Sort" / "Email": leftovers of the table header and email cell. There is no sort control in this row.
- Not designed, AI-defined: hover / focus / disabled of the button (come from `Button`), long text (cut with an ellipsis, caption up to 40% of the row), hidden action.
- The 480px button padding (12 / 8) is not a `Button` size, so it is applied as an override of the row. Dark theme not designed.

## Accessibility

- Cells have `role="row"` / `role="cell"`: put rows into a container with `role="table"` (and a header row) so the roles are valid.
- Give the button a specific name via `actionProps` (`aria-label="Edit KPI"`), because every row says "Edit".
- White on Primary Blue Dark is high contrast. The 37px button is below the 44px touch target (kept as designed).
- Dark theme contrast: text on `#000000` 12.56:1; button text `#000000` on `#BDC5E2` 12.25:1.
