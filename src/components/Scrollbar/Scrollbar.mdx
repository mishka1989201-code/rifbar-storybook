## Figma → code mapping

| Figma | What it means | In code |
|---|---|---|
| `Scrollbar Content` | Page, panel and table scroll. 11px track, 7px rounded thumb | `variant="content"` (default) |
| `Property 1=Big` / `Small` | Only the length of the drawn thumb (342px / 81px area). Not a style | A taller or shorter container: the thumb length follows the content |
| `Scrollbar.DropdownAndPopUp` | Lists in dropdowns and pop-ups. 3px track with a fill, 3px thumb | `variant="dropdown"` |

## When to use

- ✅ Any area with its own scroll: table body, side panel, long dropdown list, pop-up.

## When NOT to use

- ❌ Scrolling the whole page — the browser scrollbar is left as is.
- ❌ Content that never overflows — it draws nothing, so there is no need to wrap it.

**Figma notes:**
- A scrollbar cannot be drawn by hand in CSS, so it is styled with `::-webkit-scrollbar` (Chrome, Edge, Safari). **Firefox** cannot set the width in px: it gets its own thin scrollbar with the same colors. Hover and drag states are not drawn in Figma.
- The Content thumb is 7px wide inside an 11px track, 2px from each side and 1px from each end, with a 1px stroke of white at 15%. The 3.5px (Content) and 2px (Dropdown) radii are at least half the thumb width, so both are fully rounded: `--radius-pill` is used.
- The Content track has no fill; the Dropdown track is filled with Stroke Light V1.
- The area is focusable (`tabIndex=0`, `role="region"`) so keyboard users can scroll it. Focus is not drawn in Figma; it uses the IconButton ring.

## Dark theme

Figma frames **Dark Atoms Components → `Scrollbar Frame`** (content) and **`Scrollbar`** (dropdown & pop-up): themed `--scrollbar-*` tokens, light values unchanged. See **AllVariantsDark**.

- Content: thumb `#646464` (Secondary Grey), transparent track, the 15% white inner stroke is unchanged.
- Dropdown & pop-up: track `#242424` (Stroke Light V1), thumb `#C9C6D9` (Color Text).

Headless Chromium (used for checks) draws overlay scrollbars, so the dark scrollbars were checked by their computed colours, not by a render.

## Code example

```tsx
import { Scrollbar } from 'rifbar-ds';

<Scrollbar aria-label="Warehouses" style={{ height: 342 }}>
  {warehouses.map((w) => <Row key={w.id} {...w} />)}
</Scrollbar>

<Scrollbar variant="dropdown" aria-label="Options" style={{ maxHeight: 154 }}>
  {options}
</Scrollbar>
```

## Accessibility

- Always pass `aria-label` (or `aria-labelledby`): the area is a `region` landmark.
- ⚠️ Content thumb on a white background: `#A7A4B7` is 2.4:1, below the 3:1 for UI elements (the same Secondary Grey issue as in SearchField). Kept as designed.
- ⚠️ The Dropdown scrollbar is 3px wide: hard to grab with a mouse and below the 44px touch target. Kept as designed; touch devices scroll by swipe.
- Dark theme contrast (calculated): Content thumb `#646464` on black 3.55:1; Dropdown thumb on its track 9.29:1.
