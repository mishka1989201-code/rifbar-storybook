# TimeTracker / Title

The Play button and the title “My Time”. Implements the Figma component
[`TimeTracker/Play Buttons and Title`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=662-271081). Composes [PlayButton](?path=/docs/atoms-playbutton--docs).
The time tracker is built from four molecules: [Title](?path=/docs/molecules-timetracker-title--docs), [Date](?path=/docs/molecules-timetracker-date--docs), [Bar](?path=/docs/molecules-timetracker-bar--docs) (Title + Date) and [TimeScale](?path=/docs/molecules-timetracker-timescale--docs).

## Figma → code mapping

| Figma | Code |
|---|---|
| Frame (row, gap 16) | `.ds-time-tracker-title` |

## When to use

- ✅ Left part of the time tracker header ([Bar](?path=/docs/molecules-timetracker-bar--docs)), or alone.

## Dark theme

Figma "Dark Molecules Components" → `Play Buttons and Title Dark`: title `#5D6E82` (unchanged, 4.02:1 on `#000000`, ⚠️ below 4.5:1, as designed); the play button comes from `PlayButton`. No new tokens. Story: `DefaultDark`.

## Design tokens used

| Token | Property | Value | Source |
|---|---|---|---|
| `--spacing-16` | gap button ↔ title | `16px` | Figma |
| `--color-grey-dark` | title | `#5D6E82` | Figma: Grey Dark |
| `--font-size-h5` / `--font-line-height-h5` / `--font-weight-medium` | title | `20px` / `30px` / `500` | Figma: Medium Headings/h5 |

The button comes from `PlayButton`. No new tokens. AI-defined: ellipsis for a long title, `Stop` state (from the PlayButton atom).
