# ConfirmModal

A centred yes / no dialog: close button in the corner, a big question, a grey explanation and two actions. Implements the Figma frame [`Approve Modal`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=72-40342).
Composed of [IconButton](?path=/docs/atoms-iconbutton--docs) (close) and, in the footer, [Button](?path=/docs/atoms-button--docs)s. For form pop-ups use [Modal](?path=/docs/molecules-modal--docs).

It draws **only the dialog**: overlay, centring, scroll lock, focus trap and `Esc` belong to the page.

## When to use

- ✅ Confirming an action in one question: approve, delete, discard changes.

## When NOT to use

- ❌ Forms or several fields — use `Modal`. ❌ A message with no decision — use `Notification`.

## Figma notes

- Figma draws one dialog (630px). The destructive form (`Button variant="danger"`), the missing description / footer and the narrow width are **AI-defined**.
- The Figma description is 460px wide; the code caps it at 450px (`--size-modal-desktop`, the nearest existing token). The dialog is 100% of its container up to 630px.
- `role="alertdialog"` is used because the dialog asks for a decision; the page decides the initial focus (usually the safe button).
- Dark theme not designed.

## Code example

```tsx
import { ConfirmModal, Button } from 'rifbar-ds';

<ConfirmModal
  title="Do you want approve?"
  description="Accept user registration for further cooperation."
  onClose={close}
  actions={<>
    <Button variant="light" iconLeft="xmark" onClick={close}>Cancel</Button>
    <Button variant="dark" iconLeft="tick" onClick={approve}>Accept</Button>
  </>}
/>
```

## Accessibility

- `role="alertdialog"` with `aria-labelledby` / `aria-describedby`; the close button has an accessible name.
- The description in Secondary Grey `#A7A4B7` on white is below 3:1 contrast — kept as designed. The 40px close button and 37px buttons are below the 44px touch target.
- Dark theme contrast: see `Modal`.
