# WelcomeCard

The dashboard greeting: a dark header with the greeting, a subtitle, two key numbers and a picture on the right, and under it a stack of rows with things that need
attention. Implements the Figma component
[`Welcome Card`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/%F0%9F%93%B1-ERP-System-v-1.1--Mockups----Rifbar-2023%F0%9F%93%B1?node-id=3738-298541). It is an **organism**: the rows are [AlertRow](?path=/docs/molecules-alertrow--docs); the header is the only new markup.

## When to use

- ✅ The top block of a dashboard: who is signed in, the headline numbers and the next actions.

## When NOT to use

- ❌ A plain number with a caption — use [StatCard](?path=/docs/molecules-statcard--docs).
- ❌ Messages that stay on screen for a short time — use [Notification](?path=/docs/molecules-notification--docs).

## Figma notes

What Figma draws: one filled card — *Good Afternoon, Arnold!*, the subtitle, *New orders 14,209*, *Paid invoices $32,456.00*, a picture of vape devices on a stage, and three rows.

**The picture was not downloaded** (the Figma asset URL answers 403 through the proxy). The component takes it as `image`; the stories use a demo photo from `src/assets/demo` (sent by the designer).
Without `image` the header is the plain #0C092E fill.

Not drawn, defined by analogy (AI-defined):

- **No image, no rows, no numbers, one row, long text, narrow container** — the header content wraps; the picture stays behind it.
- **Dark theme** — designed in `Welcome Card Dark`; see the Dark theme section (the header is dark in both themes).

Normalised or assumed:

- The title and the subtitle are `h2` and `p`; the numbers are a description list. Figma only has text layers.
- The picture box (right 63.7%, 146.88% tall, shifted up 17.75%) is copied from Figma and clipped by the header. It is cropped with `cover`.
- The shadow is the Cards Shadow style (`--shadow-card`, spread -20); Figma's code draws it without the spread — the named style wins.
- Subtitle and numbers use `--theme-nav-text-active` (White / White (Light)) and the captions `--theme-nav-text` (Not Active): the same variables Figma binds on the Navbar.
- Caption / value blocks are 98px wide in Figma (`--size-welcome-stat-min`); a wider value grows its block.

## Dark theme

Figma `Dark Organisms Components` → `Welcome Card Dark` (3786:470379). Card fill `#000000`, stroke `#242424`; the header stays the dark `#0C092E` of the light theme, the greeting becomes `#888CF6`. Info rows: fill `#00161D` (new colour `success-bg-dark`), text / dot / link `#888CF6`, divider `#242424`; warning row: fill `#1B0A00`, text / dot / link `#F68F57`, line below `#5D321A`. Story `All variants (dark theme)`. The product photo is the demo image (the Figma raster was not exported); the card drops no shadow in dark (AI-defined: `--shadow-dark-1`, invisible on black).

The `--color-*` rows of the table below are light values; the last rows are the themed tokens.

## Code example

```tsx
import { WelcomeCard } from 'rifbar-ds';

<WelcomeCard
  title="Good Afternoon, Arnold!"
  subtitle="Here’s what happening with our company today"
  image="/images/welcome.png"
  stats={[
    { label: 'New orders', value: '14,209' },
    { label: 'Paid invoices', value: '$32,456.00' },
  ]}
  rows={[
    { tone: 'warning', lead: '5 types of products', children: 'will soon be out of stock', actionLabel: 'View products' },
    { tone: 'info', lead: '7 orders', children: 'are still waiting for payment', actionLabel: 'View payments' },
  ]}
/>
```

## Accessibility

- A `section` with a heading; the numbers are a description list; the picture is decorative (`aria-hidden`) and the text never sits on it alone.
- Contrast (calculated): white on the header 19.19:1; Not Active captions 12.85:1; the Hover Blue title `#6368DF` on `#0C092E` **4.18:1** (28px text, passes 3:1 for large text). Row contrasts: see `AlertRow`.
- ⚠️ Kept as designed: the card border (Stroke Light V2) is 1.31:1 against white; with a picture, text on the right part of the header could lose contrast — keep the picture dark on the left.
- Dark theme contrast, computed: greeting `#888CF6` on the header `#0C092E` 6.52:1; info row text `#888CF6` on `#00161D` 6.29:1; warning row `#F68F57` on `#1B0A00` 8.24:1; the dividers `#242424` on `#00161D` (1.19:1) and `#5D321A` on `#1B0A00` (1.78:1) are below 3:1 (kept as designed).
