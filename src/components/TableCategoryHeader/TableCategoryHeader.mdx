# TableCategoryHeader

Light header row of the categories table with sortable columns. Implements the Figma frame
[`Table Header 4`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=1299-436979)
(1524px wide in the mockup, here 100% of the container). It has no background of its own — it sits on the table/page surface.
Dark variant for the products table: [TableProductsHeader](?path=/docs/molecules-tableproductsheader--docs).

## Figma → code mapping

| Figma | Code |
|---|---|
| Frame `Table Header 4` (padding 8/16, `justify-between`) | `.ds-table-category-header` |
| “Image” 64px + “Category” 170px + sort icon, group gap 32 | columns `image` + `category`, `group: 'lead'` |
| “Flavors/Types” 170, “Colors” 150, “Puffs” 220 + sort icon | columns `flavors`, `colors`, `puffs`, `sortable: true` |
| “E-Liquid capacity” (auto width) + sort icon | column `capacity`, `sortable: true` |
| `Amount` “Actions” 84px, right-aligned | column `actions`, `align: 'end'` |
| `Icons 16px` sort-solid | `<Icon name="sort" />` (inherits label color) |

## When to use

- ✅ Header of the categories table: image, category, flavors, colors, puffs, capacity, actions.

## When NOT to use

- ❌ Dark header of the products table — use `TableProductsHeader`.
- ❌ Mobile layouts: cells have fixed widths.

## Accessibility

- `role="row"` with `role="columnheader"` cells; use it inside an element with `role="table"` (or `grid`).
- Sortable headers are real `<button>`s, reachable with Tab and activated with Enter / Space. Sort direction is not drawn in Figma, so `aria-sort` is not set.
