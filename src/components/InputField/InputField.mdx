# InputField

Form fields from the Figma component set
[`InputField`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=17-7380)
— 4 types × 6 statuses. Each Figma `Type` is its own component, because each one is a different HTML element:

| Figma `Type` | Component | HTML |
|---|---|---|
| Inputfield | `InputField` | `<input>` — one line, 32px, full width |
| Textfield | `TextField` | `<textarea>` — several lines, min 80px, full width |
| Filter | `FilterField` | `<button>` — trigger of a dropdown filter, hugs the text |
| Color | `ColorField` | `<input type="color">` — swatch + “Change”, opens the system picker |

## Figma → code mapping

| Figma `Status` | What it means | In code |
|---|---|---|
| Static | Empty: Stroke Input border, placeholder in Grey Dark | default (no value) |
| Activated | Has a value | `value` / `defaultValue` (detected automatically) |
| Hover | Mouse over | CSS `:hover` (`forceHover` for preview) |
| Focus | Typing (Input field border + Focus shadow); for Filter — the list is open | CSS `:focus`; Filter: `open` (`forceFocus` for preview) |
| Disabled | Not available | `disabled` |
| Error | Wrong value (Danger border) | `invalid` |

## When to use

- ✅ `InputField` — short text: name, number, email, search.
- ✅ `TextField` — long text: address, comment, description.
- ✅ `FilterField` — picking a value for a table / list filter.
- ✅ `ColorField` — picking a color for a tag, status, category.

## When NOT to use

- ❌ Yes / no choice — use [Checkbox](?path=/docs/atoms-checkbox--docs) or [Toggle](?path=/docs/atoms-toggle--docs).
- ❌ 2–4 options always visible — use radio buttons.
- ❌ Search with a button — use the [IconButton](?path=/docs/atoms-iconbutton--docs) `search` next to an `InputField`.

## Code example

```tsx
import { InputField, TextField, FilterField, ColorField } from 'rifbar-ds';

<InputField placeholder="Enter Text*" value={name} onChange={(e) => setName(e.target.value)} />

<TextField placeholder="Address*" rows={3} />

<FilterField placeholder="Warehouse" value={warehouse} open={open} onClick={() => setOpen(!open)} />

<ColorField value={color} onChange={(e) => setColor(e.target.value)} aria-label="Tag color" />
```

## Accessibility

- Native elements: keyboard, forms, autofill and screen readers work as usual.
- There is no visible label in the atom — always pass `aria-label` or link a `<label htmlFor>`.
  A placeholder is not a label.
- `FilterField` has `aria-haspopup="listbox"` and `aria-expanded={open}`. The `icon` prop (for example `date`) replaces the chevron for a trigger that opens a calendar; set `aria-haspopup="dialog"` then (Figma `scheduled-call-menu`).
- Contrast on White / BG Color: value text 14.7:1 / 13.8:1, placeholder 5.2:1 / 4.9:1,
  Static border 3.5:1 / 3.3:1, Activated / Focus border 6.4:1 / 6.0:1, Error border 3.5:1 / 3.3:1.
- Focus is shown by the border **and** the Focus shadow, not by color alone.
- Error is shown by the Danger border and `aria-invalid`; add a text message next to the field
  so the error is not conveyed by color only.
- ⚠️ Height 32px is below the 44px touch target — kept as designed (desktop ERP).
- ⚠️ Disabled at 20% opacity is below 3:1 contrast (same as Button).
