# PageHeader

The top bar of a page: title with the icon menu, optional breadcrumbs and optional tabs. Implements the Figma component set [`Header`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=29-18673) (`header` Default / Tabs / Bread Crumbs / Bread Crumbs & Tabs) — the four variants differ only in which rows are present, so **one component** whose variant is chosen by the `breadcrumbs` and `tabs` props.
It is composed of [`HeaderMenu`](?path=/docs/atoms-headermenu--docs), [`BreadCrumbs`](?path=/docs/molecules-breadcrumbs--docs) and [`TabsHeader`](?path=/docs/molecules-tabsheader--docs) — nothing is redrawn.

## Figma → code mapping

| Figma `header` | Code | Notes |
|---|---|---|
| `Default` | `<PageHeader title menu />` | white bar, padding 8 / 16, Cards shadow |
| `Tabs` | + `tabs` | `TabsHeader` at the bottom, no bottom padding (underline on the bar edge) |
| `Bread Crumbs` | + `breadcrumbs` | `BreadCrumbs` under the title, gap 16 |
| `Bread Crumbs & Tabs` | + `breadcrumbs` + `tabs` | title–crumbs gap 4, then tabs |
| `Title & Menu` “Clients” | `title` + `menu` | Light Headings/h2 32 / 48, Headlines; menu = `HeaderMenu` |
| Burger before the title at 1280px and below (`Icons 24px`) | `onMenuClick` (`burger-rolled-up`), `menuLabel` |
| Header at 480 / 360px (title 20 / 30) | `size="compact"` |
| `Bread Crumbs` at 768px and below (chevron + current page) | `breadcrumbs={{ variant: 'back', items }}` |
| `Header Menu` (bell, chart, support) | `menu` = `<HeaderMenu><HeaderMenuItem …/></HeaderMenu>` | the three icon flags of Figma are separate `HeaderMenuItem`s |

## When to use

- ✅ The top of every page: title, page-level actions, path and sub-navigation.

## When NOT to use

- ❌ A title inside a card — use `CardHeader`. ❌ Tabs inside a page section — use `TabsHeader` alone.

## Figma notes

- The Figma `Default` bar is drawn with a `drop-shadow` filter (`0 30 12.5 / 10%`) while the other three use `box-shadow` Cards Shadow (`0 30 25 −20 / 10%`); the code uses the Cards Shadow token everywhere (the first looks like a leftover).
- Figma shows a bell with the warning dot only; `chartIcon` and `supportIcom` flags exist in Figma and map to more `HeaderMenuItem`s (not shown by default).
- The burger and the `back` breadcrumb come from the 1280 / 1024 / 768px frames. **Needs designer confirmation:** the burger glyph (`burger-rolled-up`, short middle line, matched by look) and what the back chevron links to (here the previous crumb).
- The title is an `h1`; the page should have exactly one.
- Not designed, AI-defined: long title (wraps), many tabs (the `TabsHeader` scrolls horizontally), the layout on narrow screens (same bar, no collapsing). Dark theme not designed.

## Code example

```tsx
import { PageHeader, HeaderMenu, HeaderMenuItem } from 'rifbar-ds';

<PageHeader
  title="Clients"
  menu={<HeaderMenu><HeaderMenuItem icon="bell" label="Notifications" dot="warning" /></HeaderMenu>}
  breadcrumbs={{ items: [{ label: 'Clients' }, { label: 'All' }] }}
  tabs={{ items: [{ id: 'all', label: 'All clients' }], value: 'all', onChange }}
/>
```

## Accessibility

- A `<header>` landmark with one `<h1>`; breadcrumbs are a `nav`, tabs a `tablist` (from the composed parts).
- The burger is a button with an `aria-label`; Headlines `#4549A1` on white 7.72:1; 24px (below 44px) — kept as designed.
- Grey Dark breadcrumb root and the 32px menu buttons are below the 44px touch target — kept as designed.
