# TableRowClient

Card-like row of the clients table: name, company, phone, email, two dates and a `More` button. Implements the Figma components
[`Table Row 14`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/%F0%9F%93%B1-ERP-System-v-1.1--Mockups----Rifbar-2023%F0%9F%93%B1?node-id=17-6506) and
[`Table Row Hover Name`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/%F0%9F%93%B1-ERP-System-v-1.1--Mockups----Rifbar-2023%F0%9F%93%B1?node-id=828-255423) (the same row with the name hovered),
composed from [Button](?path=/docs/atoms-button--docs) (`variant="light"`, icon `info`).
The hover frame [`Hover Row in Table`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/%F0%9F%93%B1-ERP-System-v-1.1--Mockups----Rifbar-2023%F0%9F%93%B1?node-id=3352-240764)
(light and dark) adds the row hover fill, the delete / phone / notes buttons and a
[TooltipBordered](?path=/docs/atoms-tooltipbordered--docs) with detailed information under the row.

## When to use

- ✅ A list of clients where each row opens the client or an action menu.

## When NOT to use

- ❌ Products — use [TableProductsRow](?path=/docs/molecules-tableproductsrow--docs) or [TableRowExpandable](?path=/docs/molecules-tablerowexpandable--docs).
- ❌ Narrow screens — use [TableRowMobile](?path=/docs/molecules-tablerowmobile--docs) or `CardRow`.

## Figma notes

What Figma draws: the static row and the row with the name in Hover Blue Light and underlined, 1524px wide (no row hover fill there);
and, in `Hover Row in Table`, the first row of the clients table hovered in the light and dark themes: Row Hover fill (dark: Stroke Button), the
delete and phone buttons (a notes button too in the dark frame only) and the tooltip below the row, over the rows beneath it.

Not drawn, defined by analogy (AI-defined):

- Keyboard focus of the name: a 2px Hover Blue Light ring (the same colour as the hover; as in other DS controls).
- Long text: every cell is cut with an ellipsis.
- Name without `nameHref` / `onNameClick` is plain text and has no hover (the hover implies it is clickable).
- Dark theme: drawn only for the hovered row and its tooltip. The `--table-row-*` tokens carry those dark values for the whole row (fill, border,
  text, shadow, buttons). The resting dark row uses the same values (the dark frame has resting rows, which match). Dark hover of the buttons themselves is not designed.
- The tooltip opens on row hover **and** on keyboard focus inside the row (hover-only is not accessible), stays open while the pointer is on it,
  and Escape hides it until the pointer or focus leaves the row.
- Tooltip position: Figma draws a static mock (899px wide, 307px from the row's left edge, directly under the row, centred arrow); it is not tied to the
  hovered cell. Both numbers are new size tokens; in a narrower row the width shrinks (`max-width`). Inside `TableClients` the horizontal scroll container can clip it at the table bottom.
- The last date cell of the dark rows has a raw `#292639` text fill (almost invisible on black); the row text colour is used instead.
- Phone icon: Figma shows a solid handset; the icon `call-v2` is matched by look (needs confirmation).
- The delete button is `Red` at 60% in the light frame and solid Danger in the dark one; the 60% fill is the existing `Button variant="danger"`.

Assumed / normalised:

- The `More` button is the existing `Button` (Light Fill, small): Figma `button_action` with the `Info` icon.
- The Figma row has a drop shadow `0 4 4 rgba(0,0,0,.05)` (Table Row) while the effect list says `0 4 2`; the Table Row token is used.
- Figma lays the seven cells out with `justify-between`; the column widths are fixed (170 / 170 / 150 / 220 / 80 / 119 / 119).

## Accessibility

- Cells are `role="cell"` in a `role="row"`; place the row inside an element with `role="table"` (see [TableClients](?path=/docs/organisms-tableclients--docs)).
- The name is a real `<a>` or `<button>` when interactive; the `More` button has the visible label as its name. Add context for screen readers with `aria-label` on the row's button if several rows say only "More".
- Contrast, computed: text `#292639` on white 14.68:1, on the hover fill `#EBEBF4` 12.39:1 (dark `#C9C6D9` on `#242424` 9.29:1); `More` `#1D2542` on `#ECEEFB` 13.03:1 (dark `#BDC5E2` on `#27282E` 8.57:1);
  phone / notes icon white on `#1D2542` 15.05:1 (dark black on `#BDC5E2` 12.25:1).
- The icon-only buttons have `aria-label` (Delete, Call, Notes); the row is `aria-describedby` the tooltip when there is one. The tooltip content is not interactive.
- ⚠️ Kept as designed: white icon on the 60% red fill over the hover row is 3.16:1 (dark: white on `#ED5742` 3.48:1) — meets 3:1 for graphics, below 4.5:1; the tooltip headline is 2.29:1 / dark 3.22:1.
- ⚠️ Kept as designed: the name on hover (`#888CF6` on white) is 2.95:1, below 4.5:1 for text; the card border (`#F1F2F9` on white) is 1.12:1, and the card against the `#F6F8FC` page 1.06:1 — separated by the shadow only; the 37px `More` button is below the 44px touch target.
