# TableRowQuantity

One row of a list where the user chooses a quantity per item: the item name, its prices and a quantity field. Implements the rows of the Figma frame
[`TableRows / Choice of quantity`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/%F0%9F%93%B1-ERP-System-v-1.1--Mockups----Rifbar-2023%F0%9F%93%B1?node-id=631-216083) (10 rows: 9 empty, 1 filled), composed from [InputField](?path=/docs/atoms-inputfield--docs).

## When to use

- ✅ Choosing a quantity (or any number) per item in an order / transfer list.

## When NOT to use

- ❌ A read-only list of values — use [RowInfoBlock](?path=/docs/molecules-rowinfoblock--docs).
- ❌ A row that opens details — use [TableRowExpandable](?path=/docs/molecules-tablerowexpandable--docs).

## Figma notes

What Figma draws: 10 rows — nine with the empty field and one (`Mint Ice`) with the value `15`; two `$15` in every row; no hover or focus.

Not drawn, defined by analogy (AI-defined):

- Hover / focus / error / disabled of the field come from `InputField` (Headlines border; Input field border + Focus shadow; Danger border; 20% opacity).
- Image before the name (Figma has an empty `Image and Name` container), long name, row without prices, narrow container (the prices and field wrap under the name).
- Dark theme: not designed — light values are used.

Assumed / normalised:

- The empty field has a **Stroke Light V2** border here, while the `InputField` atom's Static border is Stroke Input (`#8A87A0`), as described in Figma's own `InputField` notes. The row overrides only the Static border; the atom stays as it is. Needs designer confirmation.
- Two of the long names in Figma (`Peach mango Watermelon`, `Malibu…`) have no fixed width; all names use the same flexible column (min 200px, wraps instead of cutting the text).
- The meaning of the two `$15` values is not named in Figma (unit price and total?), so `prices` is a plain list of nodes. The row has no sum logic.
- The drop shadow `0 4 2 rgba(0,0,0,.05)` is the existing `--shadow-table-row` (`0 4 4`) as in `TableRowExpandable`; the stroke is drawn inside.
- 200px (name and field) reuses `--size-info-row-label` (same value); it was added for another row.
- The field is a text input with `inputMode="numeric"`, not `type="number"` (no spinner, no scroll changes).

## Accessibility

- The item name labels the field (`aria-labelledby`); keyboard and form behavior come from the native `<input>`.
- ⚠️ Kept as designed: the empty field's Stroke Light V2 border on white is 1.3:1 (below 3:1 for a control boundary); the placeholder (Grey Dark) is 5.2:1.
- ⚠️ Disabled at 20% opacity is below 3:1; the 32px field is below the 44px touch target.
