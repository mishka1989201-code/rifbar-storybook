# SearchField

One-line search field with an attached search button. From the Figma component
[`SearchField`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=255-127339)
— 2 sizes × 3 styles. It is built from a native `<input type="search">` and the
[IconButton](?path=/docs/atoms-iconbutton--docs) `search`, inside a `<form role="search">`.

## Figma → code mapping

| Figma | What it means | In code |
|---|---|---|
| `Property 1=Desktop` | 32px high | `size="desktop"` (default) |
| `Property 1=Mobile` | 40px high | `size="mobile"` |
| `Style=Static` | Empty: Stroke Light V2 border, placeholder in Secondary Grey | default (no value) |
| `Style=Active` | Has text: Input field border, Color Text, dark button | `value` / `defaultValue` (detected automatically) |
| `Style=Disabled` | Not available, 20% opacity | `disabled` |

## When to use

- ✅ Search by keyword over a table or list (header, filter bar).
- ✅ Search that runs on Enter or on the button (`onSearch`).

## When NOT to use

- ❌ Entering data in a form — use [InputField](?path=/docs/atoms-inputfield--docs).
- ❌ Picking one value from a list — use `FilterField`.
- ❌ A search button without a field — use [IconButton](?path=/docs/atoms-iconbutton--docs) `search`.

## Code example

```tsx
import { SearchField } from 'rifbar-ds';

<SearchField
  value={query}
  onChange={(e) => setQuery(e.target.value)}
  onSearch={(text) => runSearch(text)}
  aria-label="Search warehouses"
/>

<SearchField size="mobile" placeholder="Search by keyword" aria-label="Search" />
```

## Accessibility

- `<form role="search">` lets screen readers jump to the search landmark; Enter submits.
- There is no visible label — always pass `aria-label` (or a linked `<label>`). A placeholder is not a label.
- The search button has `aria-label="Search"` (change it with `searchLabel`).
- Focus is shown by the Input field border **and** the Focus shadow.
- ⚠️ Static border 1.3:1 and placeholder 2.4:1 are below WCAG (see Figma notes). Value text on White is 14.7:1.
- ⚠️ Desktop height 32px is below the 44px touch target — kept as designed; Mobile (40px) is closer.
- ⚠️ Disabled at 20% opacity is below 3:1 contrast (same as Button and InputField).
