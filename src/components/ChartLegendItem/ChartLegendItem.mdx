# ChartLegendItem

One entry of a chart legend: a color swatch, a value (or "-") and the series name.
Implements the Figma component [`ChartDescription`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=88-76033).

## Figma → code mapping

| Figma | Code |
|---|---|
| Frame `ChartDescription` (row, gap 8) | `.ds-chart-legend-item` |
| Rectangle 16×16, radius 4, Hover Blue | `.ds-chart-legend-item__swatch`, `color` (default Hover Blue) |
| Text "-" | `value` (default "-", `null` hides it) |
| Text "Previous indicators" | `label` |

## When to use

- ✅ Under or next to a chart to name a series.

## When NOT to use

- ❌ Chart tooltips or axis labels — they have their own styles.

## Figma notes

- Only the Hover Blue swatch is drawn. Other series colors are AI-defined: pass any token through `color`.
- The "-" in Figma is probably a placeholder for a value; it is a prop with "-" as default.
- Long label is not designed. AI-defined: truncated with an ellipsis.
- Dark theme not designed. The legend text is black at 60% in both themes — on a dark background pass your own color via CSS.

## Accessibility

- The swatch is decorative (`aria-hidden`): color alone must not carry meaning, so keep the label.
- Black at 60% on white is about 7:1 ✅. The legend does not make a chart accessible on its own — give the chart a text alternative.
