# DepartmentItem

A department line: a square avatar with an abbreviation and the department name.
Implements the Figma component [`Department`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=139-48594) (368px wide in the mockup, here 100% of the container).
Composes the [Avatar](?path=/docs/atoms-avatar--docs) atom (`variant="department"`).

## Figma → code mapping

| Figma | Code |
|---|---|
| Frame `Department` (row, gap 8) | `.ds-department-item` |
| `Department Avatar` 28px square, radius 4, Hover Blue, "MG" | `<Avatar variant="department" initials>` |
| Text "Management" (Body/Small Regular, Grey Dark) | `name` |

## When to use

- ✅ The responsible department in a ticket, order or list.

## When NOT to use

- ❌ A person — use [UserDropdown](?path=/docs/molecules-userdropdown--docs) or `Avatar` with the `chat` variant.

## Figma notes

- Figma shows "MG" for "Management", which is not what the first letters give ("M"). So `Avatar` got an optional `initials` prop; without it the initials come from `name`.
- Long name is not designed. AI-defined: truncated with an ellipsis.
- Dark theme not designed — light values are used.

## Accessibility

- The avatar is decorative (`aria-hidden`), the name is visible text next to it.
- Name #5D6E82 on white is about 5:1 ✅. White initials on Hover Blue are 4.6:1 ✅.
