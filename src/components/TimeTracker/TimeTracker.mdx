# TimeTracker

The working-time card: the top bar with the Play button, the name and the date switcher, the statistic (Total, Break) and the day scale with the worked
periods. Implements the Figma component set
[`TimeTracker`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/%F0%9F%93%B1-ERP-System-v-1.1--Mockups----Rifbar-2023%F0%9F%93%B1?node-id=662-271601)
— 3 variants (`Property 1` Static / Active / Disabled). It is an **organism**: it only composes existing parts —
[TimeTrackerBar](?path=/docs/molecules-timetracker-bar--docs) (with `TimeTrackerTitle`, `TimeTrackerDate`, `PlayButton`) and
[TimeScale](?path=/docs/molecules-timetracker-timescale--docs). The only new markup is the statistic.

## Figma → code mapping

| Figma | Code |
|---|---|
| `Property 1=Static` | `state="static"` (default): green Play button |
| `Property 1=Active` | `state="active"`: red Stop button (the timer runs) |
| `Property 1=Disabled` | `state="disabled"`: Play at 20% opacity, not clickable |
| `TimeTracker/Play Actions Menu` | `TimeTrackerBar` — `title`, `dateLabel`, `onToggle`, `onPrev`, `onReset`, `onNext` |
| `Statistic` → two `total-time` (Total / Break) | `stats={[{ label, value }]}`, any number of pairs |
| `TimeTracker/Time Scale and Numbers` | `TimeScale` — `segments`, `scaleProps` |
| Card: white, radius 10, Cards Shadow, width 1524 | `.ds-time-tracker` (fills its container; the stories use 1524px) |

## When to use

- ✅ A day summary of one person's tracked time with start / stop control.

## When NOT to use

- ❌ Only the scale without a card — use [TimeScale](?path=/docs/molecules-timetracker-timescale--docs).
- ❌ Picking a time of day — use `TimePicker`.

## Figma notes

What Figma draws: the three variants with identical data — *David Schwimmer*, Total *1 h 59 min*, Break *23 min*, two worked periods (08:00 – 09:36 and 10:00 – 10:09).
They differ only in the Play button: green, red Stop, and a faded green Play.

Not drawn, defined by analogy (AI-defined):

- **Empty scale, no statistic, three statistics, a full day** — covered by data; the statistic wraps when it does not fit.
- **Long names** — cut with an ellipsis (`TimeTrackerTitle`); **narrow containers** — the bar wraps (`TimeTrackerBar`).
- **Hover / focus / pressed** of the buttons — from `PlayButton` and `TimeTrackerDate`.
- **Dark theme** — not designed: the light values are used.

Normalised or assumed:

- Figma's drop shadow (`0 30 12.5 rgba(0,0,0,.1)`) is the Cards Shadow style; the `--shadow-card` token is used.
- The statistic values (*1 h 59 min*, *23 min*) are not derived from the periods on the scale — Figma's numbers do not match them — so they are plain props.
- Statistic text is Color Text `#292639` (Figma code); the style list of the frame also names Primary Blue Dark. Color Text is used.
- The Semi-Bold h7 caption has line-height *Auto* in Figma; `--font-line-height-h7` (21px) is used.
- The Play and Stop glyphs and the worked-time gradient come from `PlayButton` / `TimeScale` (the Figma raster fills were sampled earlier).

## Accessibility

- The statistic is a description list (`dl`), so a screen reader reads each caption with its value; the scale has a text alternative of the worked periods (`TimeScale`).
- The Play / Stop button has an accessible name (“Play” / “Stop”); `state="disabled"` sets the native `disabled`.
- Contrast (calculated, on white): statistic text `#292639` 14.68:1; hour labels Headlines `#4549A1` 7.72:1; name Grey Dark `#5D6E82` 5.23:1.
- ⚠️ Kept as designed: the empty scale track (Stroke Light V2 `#D8E2EE`) is 1.31:1 against white; the disabled Play button at 20% opacity is below 3:1; the 32–38px buttons are below the 44px touch target.
- Dark theme contrast: stats `#C9C6D9` on `#000000` 12.56:1.
