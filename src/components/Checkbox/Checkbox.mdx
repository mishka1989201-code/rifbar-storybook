# Checkbox

Checkbox and radio button. Implements the Figma component set
[`Checkbox`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=32-45267)
— 2 types × 6 statuses × 2 sizes. Built on a native `<input>`, so it works in forms, with the keyboard and with screen readers.

## Figma → code mapping

| Figma property | Figma value | Prop |
|---|---|---|
| Type | Checkbox / Radiobutton | `type="checkbox" \| "radio"` |
| Size | 24px / 16px | `size={24} \| {16}` |
| Status | Chosen / Unchosen | `checked` (or `defaultChecked`) |
| Status | … Hover | CSS `:hover` (`forceHover` for preview) |
| Status | … Disabled | `disabled` |

## When to use

- ✅ **Checkbox** — independent on/off choices, multi-select in tables and filters.
- ✅ **Radiobutton** — one choice out of 2–5 visible options. Give all radios of a group the same `name`.
- ✅ **24px** — forms and settings; **16px** — dense tables and filter lists.

## When NOT to use

- ❌ A single radio button on its own — use a checkbox.
- ❌ More than ~5 radio options — use a dropdown.
- ❌ Actions that apply immediately (e.g. turning a feature on) — a toggle/switch fits better (not in the DS yet).

## Dark theme

Figma frame **Dark Atoms Components → `Checkbox`**: themed `--checkbox-*` tokens, light values unchanged. See **AllVariantsDark**.

- Chosen fill `#888CF6`, mark / radio dot `#050411`; Hover (chosen and unchosen) `#4549A1`; Unchosen fill `#000000`, stroke `#5D6E82`; Disabled 20% opacity.
- In dark, Hover is *darker* than the resting colour (`#888CF6` → `#4549A1`), the reverse of the light theme (`#4549A1` → `#6368DF`) — as drawn in Figma.
- The label colour is not drawn in Figma; `--control-label` (`#BDC5E2` in dark) is AI-defined, same as Button.

## Code example

```tsx
import { Checkbox } from 'rifbar-ds';

<Checkbox checked={selected} onChange={(e) => setSelected(e.target.checked)} aria-label="Select row" />
<Checkbox size={16} defaultChecked>Show archived orders</Checkbox>
<Checkbox type="radio" name="delivery" value="courier" checked={d === 'courier'} onChange={() => setD('courier')}>
  Courier
</Checkbox>
```

## Accessibility

- Native `<input type="checkbox|radio">` inside a `<label>` — Space toggles, arrow keys move between radios with the same `name`.
- Without `children`, pass `aria-label` (e.g. table row selection).
- Group related options in `<fieldset>` with a `<legend>`.
- ⚠️ Touch target: 24×24 / 16×16 px (below 44×44). With a label the whole label is clickable. Kept as designed — desktop ERP.
- ⚠️ Disabled at 20% opacity is below 3:1 contrast — flag to design (same as Button).
- Dark theme contrast (calculated): Chosen `#888CF6` on black 7.13:1, mark on it 6.91:1; Unchosen stroke `#5D6E82` 4.02:1;
  ⚠️ Hover `#4549A1` on black **2.72:1** and the mark on a hovered Chosen box **2.64:1** (below 3:1) — as designed, flag to design.
