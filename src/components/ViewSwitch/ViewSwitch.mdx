# ViewSwitch

“View:” switch above a list: two icon buttons — cards and list. Implements the Figma component
[`viewing style`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=68-25756) and its hover state
([`828:254538`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=828-254538)). Composes [Icon](?path=/docs/atoms-icon--docs) (`cards-view`, `list-view`).

## Figma → code mapping

| Figma | Code |
|---|---|
| Frame `viewing style` (row, gap 8) | `.ds-view-switch` |
| “View:” (Semi-Bold Headings/h7, Headlines) | `label` |
| `Icons 24px` List View, Primary Blue Dark | chosen button (`is-active`) |
| `Icons 24px` Cards, Secondary Grey | not chosen button |
| Cards in Hover Blue Light (`828:254538`) | `:hover` of the not chosen button |

## When to use

- ✅ Switching a catalog or table between a card grid and a list.

## When NOT to use

- ❌ Switching more than two views or tabs — use [TabsHeader](?path=/docs/molecules-tabsheader--docs).

## Accessibility

- A `group` named by the label; each icon button has an `aria-label` and `aria-pressed`.
- Dark theme contrast: label 7.13:1; inactive icon `#646464` on `#000000` 3.55:1.
