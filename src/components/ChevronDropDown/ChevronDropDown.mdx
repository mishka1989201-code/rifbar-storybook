# ChevronDropDown

A small pill with a label and an arrow that **opens a list of options** (filter, status, warehouse…). Implements the Figma component
[`Chevron.DropDown`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=78-15533).
Built from [Icon](?path=/docs/atoms-icon--docs) `arrow-drop-down` / `arrow-drop-up`.

This is only the **trigger**. The list itself is drawn by the parent (a DS dropdown list will come later as a molecule).

## Figma → code mapping

The Figma variant names do not match the board labels — code follows the **board labels**:

| Board column | Figma variant | Code | Look |
|---|---|---|---|
| Static | `Status=Static` | default | 1px stroke + text in the color |
| Hover / Focus | `Status=Focus or pressed` | `:hover`, `:focus-visible` (`forceHover` for docs) | + colored glow 4px |
| Active | `Status=Hover` | `open` | darker color, arrow **up**, `aria-expanded="true"` |
| Disabled | `Status=Static` @ 20% | `disabled` | 20% opacity |

| `color` | Static | Active (open) | Glow |
|---|---|---|---|
| `primary` | Hover Blue `#6368DF` | `#4D51B5` | Hover Blue 70% |
| `secondary` | Grey Dark `#5D6E82` | `#3E4A57` | Grey Dark 60% |
| `success` | Green Light `#1FD246` | `#1DA73B` | Green Light 70% |
| `info` | Headlines `#4549A1` | `#1997BE` | Blue Light 60% |
| `warning` | Warning `#F68F57` | `#DA6C31` | Warning 60% |
| `danger` | Danger `#ED5742` | `#BF3C2A` | Danger 70% |
| `light` | BG Color fill, Grey Dark text, no stroke | + Grey Dark stroke | Grey Dark 40% |
| `dark` | Primary Blue Dark `#1D2542` | `#505978` | Primary Blue Dark 60% |
| `white` | White text, no frame (Body/Small Medium) | Secondary Light `#ECEEFB` | White 2px glow on text |

## When to use

- ✅ A compact choice in a filter bar or a card header: status, period, warehouse.
- ✅ `white` on dark headers / dark panels.

## When NOT to use

- ❌ A form field with a label — use [InputField](?path=/docs/atoms-inputfield--docs).
- ❌ A status that cannot be changed — use [ChevronStatus](?path=/docs/atoms-chevronstatus--docs).
- ❌ An applied filter with × — use [FilterChevron](?path=/docs/atoms-filterchevron--docs).

- **Hover and keyboard focus look the same** (Figma: one column). The glow is the focus indicator.
- **Hover while open** — not designed: the glow is added on top of the open look.
- **Loading, error, empty** — not applicable to the trigger. An empty list is the list’s job.

**Figma notes:**
- `info` uses **Headlines** for stroke and text, but its glow and open color are from the **Blue Light** family (as drawn in Figma).
- `white` in Figma uses a Font Awesome caret glyph — in code it is the DS `arrow-drop-down` icon for consistency.
- `white` in Figma: Medium 14 / 19 with 5px padding = 29px. Code: Body/Small line 21px + 4px padding = the same 29px, using existing tokens.
- Open colors and glows are raw values in Figma (no variables) — added as tokens below.
- No dark theme in Figma. On dark backgrounds use `white`.

## Code example

```tsx
import { ChevronDropDown } from 'rifbar-ds';

const [open, setOpen] = useState(false);

<ChevronDropDown color="secondary" open={open} aria-controls="status-menu" onClick={() => setOpen(!open)}>
  {status}
</ChevronDropDown>
{open && <ul id="status-menu" role="menu">…</ul>}
```
