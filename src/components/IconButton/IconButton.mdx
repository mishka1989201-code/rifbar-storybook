# IconButton

Small square button for Search, Pagination and Close. Implements the Figma component set
[`Icon Button`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=17-7376)
— 5 kinds × 4 statuses.

## Figma → code mapping

| Figma property | Figma value | Prop |
|---|---|---|
| Icon Button | Search | `kind="search"` (32×32, icon `search` 16px) |
| Icon Button | Pagination Number | `kind="page"` + number as children (40×40) |
| Icon Button | Pagination Arrow Left | `kind="prev"` (40×40) |
| Icon Button | Pagination Arrow Right | `kind="next"` (40×40) |
| Icon Button | Close | `kind="close"` (40×40, icon `xmark` 24px) |
| Status | Static | default |
| Status | Hover | CSS `:hover` (`forceHover` for preview) |
| Status | Active | `active` — also shown while the button is pressed |
| Status | Disabled | `disabled` |

## When to use

- ✅ **search** — opens / toggles a search field in a toolbar or table header.
- ✅ **page / prev / next** — pagination under tables and lists. Mark the current page with `active`.
- ✅ **close** — closes modals, drawers, side panels.

## When NOT to use

- ❌ Any other icon action (export, delete…) — use [Button](?path=/docs/atoms-button--docs) with `iconOnly`.
- ❌ Text labels other than a page number in `kind="page"`.
- ❌ Disabled Close — a dialog should always be closable.

## Code example

```tsx
import { IconButton } from 'rifbar-ds';

<IconButton kind="search" active={searchOpen} onClick={toggleSearch} />
<IconButton kind="prev" disabled={page === 1} onClick={prevPage} />
<IconButton kind="page" active={page === 3} onClick={() => setPage(3)}>3</IconButton>
<IconButton kind="next" onClick={nextPage} />
<IconButton kind="close" onClick={onClose} />
```

## Accessibility

- Native `<button>` with `type="button"` by default.
- Default `aria-label`s: “Search”, “Previous page”, “Next page”, “Close”, “Page N” — override with your own `aria-label` (e.g. Ukrainian copy).
- `kind="page"` + `active` → `aria-current="page"`; `kind="search"` → `aria-pressed`.
- Wrap pagination in `<nav aria-label="…">`.
- ⚠️ Touch target: 32×32 / 40×40 px (below 44×44). Kept as designed — desktop ERP.
- ⚠️ Disabled at 20% opacity is below 3:1 contrast — flag to design (same as Button).
