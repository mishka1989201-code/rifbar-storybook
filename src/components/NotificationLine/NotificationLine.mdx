A row of the notifications list: message text with a warning icon and the date underneath.

## Figma notes

- Figma draws the row at a fixed 1524px; in code it is 100% of its container.
- Hover and Disabled are drawn in Figma; Focus is **not** (the row is not interactive). Not designed, AI-defined: long text wraps (`overflow-wrap: anywhere`); without `date` the time line is omitted; `disabled` also sets `pointer-events: none`.
- Figma `Type=Old / Hover` has the stroke; `Old / Static` has none — the stroke is drawn as an inset `box-shadow` (colour `transparent` when absent) so the size stays exact.
- The icon is the Figma `Icons 16px` warning glyph (mask group, no visible name); matched to the existing `warning-v2` and coloured with Warning `#F68F57`. Needs designer confirmation.
- The raw stroke `#D6DBEE` of `New / Static` has no Figma variable, hence the new token.
- Dark theme not designed: light values are used.

- `popup`: Figma draws only one state (text, no date). **AI-defined:** `type="new"` and hover use the `--color-bg` fill (as the unread / hover row of `Dropdown` notifications), disabled = 20%, `date` (optional) goes under the text in Grey Dark. The icon is the same unnamed warning glyph, matched to `warning-v2`. The row is the same as a `Dropdown variant="notifications"` row; `Dropdown` keeps its own markup (it needs button semantics and the “See all” footer).

## Accessibility

- Plain text in a `div`; when the row is clickable, wrap it in a link/button yourself. `disabled` sets `aria-disabled`.
- Disabled at 20% opacity is below 3:1 contrast — kept as designed.
- Date Grey Dark `#5D6E82` on white / Row Hover passes 4.5:1; the warning icon `#F68F57` on white is below 3:1 (decorative, kept as designed).
