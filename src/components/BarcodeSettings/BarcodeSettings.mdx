# BarcodeSettings

One panel of the barcode card: type the text to generate a barcode from, upload a file with one, or look at the result. Implements the Figma component set [`BarcodeSettings`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=7064-74791) (`Property 1` Information1 / 2 / 3) — the three panels share the frame, so **one component** with `mode`.
Composed of `TextField`, [`FileDropzone`](?path=/docs/atoms-filedropzone--docs) and two `Button`s.

## When to use

- ✅ Setting the barcode of a product: type or upload, confirm, see the result.

## When NOT to use

- ❌ A plain text form — use `LabeledField` + `InputField`.

## Figma notes

- Figma draws the confirm button at 20 % (disabled) in both forms. **AI-defined:** `generate` enables it when the text is not empty; `upload` waits for `canSubmit`. The filled field and the chosen file are not drawn.
- The Figma barcode is a raster image (`7 50015 00000 6`); the stories use a drawn stand-in. The real picture is passed as `image`.
- The right line of the panel (Secondary Light) separates it from the next column; three panels side by side form the card. A panel at the end of a row keeps the line — hide it with a wrapper or `className` if needed.
- The 9px gap between the dropzone icon and text is 8 in code (no 9px token). The Figma panel height (257 for Information3) is not fixed: the preview is 193px high (257 − 2 × 32).
- Dark theme not designed.

## Code example

```tsx
import { BarcodeSettings } from 'rifbar-ds';

<BarcodeSettings mode="generate" value={text} onChange={setText} onSubmit={generate} />
<BarcodeSettings mode="upload" dropzoneProps={{ accept: 'image/*', onFiles }} canSubmit={!!file} onSubmit={accept} />
<BarcodeSettings mode="preview" image={url} imageAlt="Barcode 7 50015 00000 6" />
```

## Accessibility

- Each form panel is a `role="group"` named by its title; the text field is labelled by the same title.
- The disabled confirm button is 20 % opacity — below 3:1, kept as designed. Buttons are 37px high, below the 44px touch target.
- The preview needs a meaningful `imageAlt` (the barcode number); the default “Barcode” is only a fallback.
