# SwitchButtons

A group of buttons that switches which part of one list is shown (All clients / Pending (8)).
Implements the Figma component set
[`SwitchButtons`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/ERP-System-v-1.1--Mockups----Rifbar-2023?node-id=13-14035)
— 4 variants. In code the atom is `SwitchButton`; a group is several `SwitchButton` in a `role="group"`.

## Figma → code mapping

| Figma property | Figma value | Prop |
|---|---|---|
| Tab | Active | `active` |
| Tab | Not Active | `active={false}` (default) |
| Style | Dark | `variant="dark"` (default) |
| Style | Light | `variant="light"` |

`Style` only changes the active button. Not Active looks the same in both styles.

## When to use

- ✅ 2–4 filters of one list, shown above the list or table.
- ✅ Dark — the main filter of the page. Light — a quieter filter inside a card. *(AI suggestion — confirm with design.)*

## When NOT to use

- ❌ Switching between different sections of a page — use [Tabs](?path=/docs/atoms-tabs--docs).
- ❌ An on/off setting — use [Toggle](?path=/docs/atoms-toggle--docs).

## Code example

```tsx
import { SwitchButton } from 'rifbar-ds';

const [filter, setFilter] = useState<'all' | 'pending'>('all');

<div role="group" aria-label="Clients filter" style={{ display: 'flex', gap: 'var(--spacing-8)' }}>
  <SwitchButton active={filter === 'all'} onClick={() => setFilter('all')}>All clients</SwitchButton>
  <SwitchButton active={filter === 'pending'} onClick={() => setFilter('pending')}>Pending (8)</SwitchButton>
</div>
```

## Accessibility

- `<button aria-pressed>`; wrap the group in `role="group"` with an `aria-label`.
- Contrast: White on Primary Blue Dark 15.0:1, Primary Blue Dark on Secondary Light 13.0:1, Grey Dark on White 5.2:1.
- Touch target: 48px high — OK.
