# AlertRow

A tinted row that points at something needing attention: a colored dot, one sentence (Medium lead + Regular rest) and a `Text & Arrow` action at the right.
Implements the rows `Option 1`, `Option 4` and `Option 5` of the Figma
[`Welcome Card`](https://www.figma.com/design/4Q7E8IQ07a9xFiNVBfmo4M/%F0%9F%93%B1-ERP-System-v-1.1--Mockups----Rifbar-2023%F0%9F%93%B1?node-id=3738-298541). They differ only in color and text, so they are **one molecule** with a `tone`.
The action is the existing [Button](?path=/docs/atoms-button--docs) `variant="text-arrow"`.

| `Option 4` / `Option 5` (Success BG, Hover Blue) | `tone="info"` (default) |
| Bold part of the text (Medium) | `lead` |
| Regular part of the text | `children` |
| `button_action` (Text & Arrow) | `actionLabel`, `onAction`, `actionProps` |
| Dot 8×8 | drawn by the component, color follows `tone` |
| Bottom line 1px Stroke Light V2 (not on the last row) | automatic between stacked rows |

## When to use

- ✅ A short list of things to look at on a dashboard: low stock, unpaid orders, items to approve.

## When NOT to use

- ❌ A system message with a title and a close button — use [Notification](?path=/docs/molecules-notification--docs).
- ❌ A row of the notifications list with a date — use [NotificationLine](?path=/docs/molecules-notificationline--docs).

## Figma notes

What Figma draws: three rows, 810px wide, 45px high (12px vertical padding, 21px content), with the actions *View products*, *View payments*, *View orders*.
The numbering (1, 4, 5) suggests Options 2 and 3 exist in Figma but are not in this frame; only two colors are known, so `tone` has two values.

Not drawn, defined by analogy (AI-defined):

- **Hover / focus / disabled** of the action — from `Button` `text-arrow`; on hover the action takes the row's text color.
- **Row without an action, lead only, long text, narrow container** — the sentence wraps and the action never shrinks.
- **Dark theme** — designed in `Welcome Card Dark`; see the Dark theme section.

Normalised or assumed:

- The text is 13px in Figma without a text style; a new token `--font-size-notice` is added. The line-height is the Small one (21px) so the row is 45px high.
- The dot color is not readable from the code (SVG asset not downloaded); it is read from the render: the row action color (Warning / Hover Blue) — **needs confirmation**.
- Warning rows use Warning (Dark) `#A7572C` for the text, as in the Figma variable; the token is named “dark theme” in `tokens.json`.
- Figma assets were not used; the dot is CSS and the chevron is the `Icon` set.

## Accessibility

- The action is a native `button`; the dot is decorative (`aria-hidden`) — the color is never the only carrier of meaning, the sentence says it.
- Contrast (calculated): warning text `#A7572C` on `#FFF5F0` 4.84:1; info text `#6368DF` on `#F3FFFA` **4.48:1** (13px text, just below 4.5:1); warning action `#F68F57` on `#FFF5F0` **2.18:1**.
- ⚠️ Kept as designed: the warning action is below 3:1; the 21px action is below the 44px touch target.
- Dark theme contrast, computed: info text `#888CF6` on `#00161D` 6.29:1; warning text `#F68F57` on `#1B0A00` 8.24:1; dividers 1.19:1 / 1.78:1 (below 3:1, kept as designed).
